2026年10月15日の夕方、北海道網走市美岬の国有林で山林火災が起きました。

山火事というと春のイメージがあります。実際にデータを見ても、ピークははっきり春です。ただ、秋に起きないわけではありません。軽く整理しておきます。

---

## 網走の山林火災（10月16日時点）

| 項目 | 内容 |
|---|---|
| 発生 | <strong>10月15日夕方</strong>、網走市美岬の国有林（能取湖の近く） |
| 焼損面積 | <strong>約75ヘクタール</strong>（16日時点、鎮火していない） |
| 被害 | けが人、住宅への被害は確認されていない |
| 消火 | 消防車両が近づけない場所のため、道が<strong>自衛隊に災害派遣を要請</strong>。自衛隊ヘリ3機と道の防災ヘリ1機が空中から散水 |
| 気象 | <strong>18日まで乾燥注意報</strong> |

地上から近づけない場所では、ヘリによる空中消火が頼りになります。ヘリの消火の考え方については、[ヘリコプターによる山林火災消火](/blog/helicopter-firefighting-2026/)の記事で書きました。

## 山火事のピークは春

消防庁と林野庁の資料から、2023年の林野火災の月別件数を見てみます。

| 月 | 件数 | 割合 |
|---|---|---|
| 1月 | 115 | 8.9% |
| 2月 | 132 | 10.2% |
| <strong>3月</strong> | <strong>325</strong> | <strong>25.0%</strong> |
| <strong>4月</strong> | <strong>222</strong> | <strong>17.1%</strong> |
| 5月 | 85 | 6.5% |
| 6月 | 19 | 1.5% |
| 7月 | 44 | 3.4% |
| 8月 | 81 | 6.2% |
| 9月 | 30 | 2.3% |
| <strong>10月</strong> | <strong>85</strong> | <strong>6.5%</strong> |
| 11月 | 72 | 5.5% |
| 12月 | 89 | 6.9% |

<small>出典：消防庁・林野庁「林野火災の現状と予防に係る取組状況」（2023年中、全1,299件）</small>

<strong>2〜4月の3か月で全体の約52%</strong>です。消防庁と林野庁は、春に多い理由として、空気が乾燥して強い風が吹く時期であること、火入れ（枯れ草を焼くこと）が行われること、山菜採りやハイキングで山に入る人が増えることを挙げています。

北海道はもう少し遅く、<strong>雪解け後の4〜5月</strong>が山場です。道は3〜6月を林野火災の危険期間としていて、2024年に道内で起きた10件のうち8割が4〜5月でした。

## それでも、秋にも小さな山がある

表をもう一度見ると、<strong>6〜9月はいったん少なくなり、10月から12月にかけて件数が戻っています。</strong>10月の85件は5月と同じ数です。

秋は、落ち葉や枯れ草が増えて、燃えるものが地表にたまっていく季節です。北海道なら、雪が積もるまでの間、それが乾いたまま残ります。そこに乾燥と風が重なれば、今回のように大きく燃え広がることがあります。

そして、原因の大部分は人です。2023年の出火原因は、<strong>たき火が32.0%、火入れが19.0%</strong>で、放火（疑いを含む）、たばこと続きます。季節に関係なく、<strong>火を使う人がいれば山火事は起きます。</strong>

## 秋も注意しましょう

- <strong>たき火や枯れ草焼きは、乾燥注意報が出ている日や風の強い日にはやめる</strong>
- <strong>山に入るときは、たばこやバーナーの火の始末を確実に</strong>
- <strong>市町村の火入れのルールや、林野火災の注意報・警報を確認する</strong>（東京消防庁は2026年4月から[林野火災注意報・警報](/blog/tokyo-forest-fire-2026/)の運用を始めています）

飛ぶ側としては、山火事の煙は視程を大きく落とします。秋の晴れた日でも、乾燥注意報が出ているときは、ルート上やその風下に煙がないかを気にかけておきたいところです。

## まとめ

- 2026年10月15日、<strong>北海道網走市の国有林で山林火災</strong>。約75ヘクタールが焼け、自衛隊に災害派遣が要請された（16日時点）。
- 山火事のピークは<strong>春</strong>。全国では<strong>2〜4月に約52%</strong>、北海道は<strong>雪解け後の4〜5月</strong>に集中する。
- ただし<strong>10〜12月にも小さな山</strong>があり、2023年は10月が85件で5月と同じだった。
- 原因の大部分は<strong>たき火や火入れなどの人的要因</strong>。<strong>秋も、乾燥した日の火の扱いには注意を。</strong>
