場外離着陸や低空飛行の許可申請を、オンラインで出せるのが <strong>AOPS（航空機運航情報処理システム）</strong>です。国土交通省航空局が運用していて、許可書も電子で受け取れます。

便利な一方で、「申請する前に登録しておくもの」がいくつかあり、初めてだと手が止まりがちです。公式の操作マニュアルとよくある質問から、<strong>登録方法と、最低限の操作の流れ</strong>をまとめました。

- AOPS：[https://www.aops.mlit.go.jp/aops/top](https://www.aops.mlit.go.jp/aops/top)

先に全体像です。

1. <strong>アカウントを開設する</strong>（個人か法人）
2. <strong>事前登録をする</strong>——航空機、操縦者、同乗者（81条）、離着陸場所（79条）
3. <strong>新規申請をする</strong>——条文と場所を選び、内容を入力し、図面を添付して提出
4. <strong>許可書をダウンロードする</strong>（電子許可書）
5. 2回目からは、<strong>継続申請・再申請</strong>や<strong>複写</strong>で手間を減らす

---

## AOPSでできること

| 手続 | 条文 |
|---|---|
| 空港等以外の場所における離着陸の<strong>許可申請</strong>（場外離着陸） | 航空法第79条ただし書 |
| 最低安全高度以下の高度での飛行の<strong>許可申請</strong>（低空飛行） | 航空法第81条ただし書 |
| 物件投下の<strong>届出</strong> | 航空法第89条ただし書 |

1回の飛行に複数の条文が関わる場合（場外離着陸と低空飛行など）は、<strong>まとめて1つの申請</strong>にできます。

<strong>システム利用料は無料</strong>で、メンテナンス時間を除いて<strong>24時間</strong>使えます。日本以外からも利用できます。

申請先（東京航空局・大阪航空局、東京空港事務所・関西空港事務所）の振り分けは、[低空飛行の許可は何を・どこに出すのか](/blog/low-altitude-permit-where-2026/)の記事で整理しました。AOPSでは、場所と航空機を選ぶと<strong>申請先が自動で表示</strong>されます。

## 始める前に確認しておくこと

| 項目 | 内容 |
|---|---|
| 動作環境 | <strong>OSはWindows、ブラウザはEdge</strong>に対応。スマートフォン、iPad、Androidタブレット、Chromebookは動作保証の対象外 |
| メール | <strong>メールアドレスが必須</strong>。通知は <code>information@aops.mlit.go.jp</code> から届くので、受信できるよう設定しておく |
| 申請の時期 | 許可が必要な日の<strong>1〜2週間前</strong>までに申請。不備があると確認に時間がかかる |
| 放置すると | 申請手続き中に<strong>120分以上</strong>操作しないと自動でログアウトされ、やり直しになる |
| ブラウザ操作 | ブラウザの<strong>「戻る」「更新」ボタンは使わない</strong>。画面上の「戻る」「次へ」ボタンを使う |
| タブ・端末 | <strong>複数のタブやウィンドウ</strong>で同時に開かない。<strong>複数の端末での同時ログイン</strong>もしない |
| 文字 | 「髙」などの一部の特殊文字は使えない（「高」で代用） |
| 印刷 | PDF出力や印刷の機能はない。必要ならブラウザの印刷機能を使う |

入力欄の横にある「？」マークにマウスを合わせると、その欄に何を入れればよいかの説明が出ます。

## ① アカウントを開設する

トップページの「<strong>個人の方のアカウント開設</strong>」か「<strong>企業・団体の方のアカウント開設</strong>」から始めます。利用規約に同意して、必要な情報を入力します。

| | 個人 | 法人（企業・団体） |
|---|---|---|
| 入力する情報 | 氏名、フリガナ、住所、生年月日、電話番号、メールアドレス | 法人番号、企業・団体名、代表者氏名、本店または主たる事務所の所在地、担当者の所属・氏名・国/地域・電話番号・メールアドレス |
| 入力の補助（任意） | <strong>マイナンバーカード</strong>（ICカードリーダーか、スマホでの読み取り） | <strong>gBizID</strong>（プライム、メンバー、エントリー） |

- マイナンバーカードやgBizIDと連携しなくても、アカウントは開設できます。
- 氏名は姓と名の間にスペースを入れます。電話番号はハイフンなしで入力します。
- パスワードは、英字・数字・記号を使って<strong>8〜32文字</strong>です。
- 開設すると、登録したメールアドレスに<strong>ログインID</strong>が届きます。パスワードは通知されないので、自分で管理します。
- ログインにマイナンバーカードは不要です。IDとパスワードでログインします。

会社として申請するなら<strong>法人アカウント</strong>、個人で申請するなら<strong>個人アカウント</strong>を開設します。アカウントで登録した情報は、各申請に自動で転記されます。

## ② 事前登録をする——ここを済ませないと申請できない

申請の画面では、航空機や操縦者を<strong>一覧から選ぶだけ</strong>で、その場で新しく追加することはできません。<strong>申請の前に、メインメニューの「許可申請（届出）に必要な情報を準備する」で登録しておく</strong>必要があります。

| 登録するもの | いつ必要か | 入力する項目 |
|---|---|---|
| <strong>航空機情報</strong> | すべての手続 | 航空機の種類（飛行機／回転翼航空機など）、<strong>型式名</strong>（一覧から選択。なければ直接入力）、<strong>国籍・登録記号</strong>（半角、スペースなし） |
| <strong>操縦者情報</strong> | すべての手続 | 操縦者氏名、<strong>所有資格</strong>（定期／事業用／自家用／法第28条許可／その他）、技能証明番号（任意）、限定事項（任意） |
| <strong>同乗者情報</strong> | <strong>81条（低空飛行）</strong>の手続 | 同乗者氏名、<strong>同乗の目的</strong> |
| <strong>離着陸場所</strong> | <strong>79条（場外離着陸）</strong>の手続 | 名称・フリガナ、<strong>住所</strong>（領海上・公海上も可）、緯度・経度（任意）、<strong>種別</strong>、土地所有者（または管理者）と連絡先（任意）、<strong>離着陸の時間帯</strong>（夜間を含むか）、夜間なら<strong>灯火施設</strong> |

### 登録のコツ

- 英数字は<strong>半角</strong>で入力します（全角英数字は入力できません）。
- 操縦者の資格を複数持っている場合、<strong>資格ごとに別の操縦者情報</strong>として登録します。ただし、申請に必要な資格が登録されていれば、全部を登録する必要はありません。
- 離着陸場所の<strong>種別</strong>は、地上（一般／特殊地域／防災対応／路線）、建築物（一般／路線）、建築物以外の構築物（一般／特殊地域）から選びます。
- 夜間に離着陸する場所は「<strong>夜間を含む</strong>」にチェックします。「終日」を選ぶと自動でチェックが入り、風向灯・境界灯にもチェックが入ります。
- 土地所有者が変わったときは、「離着陸場所の登録・変更」から<strong>情報を更新</strong>します。
- ただし、<strong>登録済みの離着陸場所のIDを、別の場所の情報に書き換えるのは避けます</strong>。IDは、継続申請のときに過去に許可を受けた場所と紐付けるのに使われるためです。別の場所は新しく登録します。
- 登録を削除すると、その情報を使った過去の申請の<strong>継続申請ができなくなります</strong>。削除は慎重に。

## ③ 新規申請をする

メインメニューの「<strong>新規申請（新規届出）</strong>」を押し、「新規申請」を選びます。流れは次のとおりです。

| 手順 | 画面 | やること |
|---|---|---|
| 1 | 手続の選択 | <strong>条文</strong>（79条・81条・89条、複数選択可）、<strong>航空機の種類</strong>、<strong>場所</strong>（東日本／西日本／公海上）を選ぶ。該当する航空機（運送事業・夜間など）を選ぶと、<strong>申請先が自動で表示</strong>される |
| 2 | 基本情報 | 申請者情報（アカウントから自動入力）、<strong>緊急時の連絡先</strong>、<strong>飛行目的、飛行期間・時間、飛行経路</strong>を入力 |
| 3 | 79条の場合 | 登録済みの<strong>離着陸場所を選ぶ</strong>。図面の添付、離着陸の理由、事故防止の措置、標識・風向指示器・附帯施設・灯火などを入力 |
| 4 | 81条の場合 | <strong>低空飛行を行う経路</strong>（都道府県＋市区町村、番地は不要）と<strong>高度</strong>（下限〜上限、mかft）を入力。図面を添付し、理由を選ぶ |
| 5 | 89条の場合 | 投下の目的、<strong>投下物件</strong>（名称・形状・重量）、<strong>投下場所</strong>（<strong>番地まで</strong>）、高度、図面、危害予防措置を入力 |
| 6 | 選択 | 登録済みの<strong>操縦者</strong>、<strong>航空機</strong>、（81条なら）<strong>同乗者</strong>を選ぶ |
| 7 | 確認・提出 | 内容を確認して提出。<strong>確認ダイアログで「OK」を押した日が申請日</strong>になる |
| 8 | メール | 提出完了のメールが届く |

### 入力のポイント

- 場所が<strong>東日本と西日本にまたがる</strong>場合は、<strong>それぞれ別に申請</strong>します。
- <strong>地方航空局と空港事務所にまとめて申請することはできません</strong>（例：東京航空局と東京空港事務所）。それぞれに手続します。
- 飛行の時間帯に<strong>夜間が含まれる</strong>場合は、必ず「<strong>夜間を含む</strong>」を選びます。
- 日によって飛行時間が違う場合は、<strong>いちばん広い時間帯</strong>を選び、備考欄に内訳を書きます（例：「○/○〜○/○は○時〜○時」）。終日の場所と日中だけの場所が混ざる場合は「終日」を選びます。
- 81条で、同じ市区町村の中に低空飛行の場所が複数あるときは、<strong>市区町村ごとに1行</strong>にまとめて「合計○か所」と入力し、詳しい場所は図面で示せます。行は「追加入力」で最大200件まで増やせます。
- 過去に<strong>書面やメールで許可を受けた場所</strong>でも、AOPSで初めて申請するときは「<strong>新規申請</strong>」から出します。「その他参考となる事項」に、過去の申請日・許可日・許可番号を書きます。

### 添付する図面

79条と81条では、それぞれ次の図面を添付します。

| 条文 | 添付する図・資料 |
|---|---|
| <strong>79条</strong> | 離着陸地帯等の<strong>実測図</strong>、離着陸地帯の最近の<strong>路面の状況</strong>を示す図、<strong>進入区域・転移表面の投影図</strong>と場周飛行の範囲内の<strong>障害物の位置・高さ</strong>、<strong>人家の密集の程度</strong>を示す図、（夜間なら）<strong>灯火施設の配置図</strong>と灯光・光度が分かる資料 |
| <strong>81条</strong> | <strong>経路上の飛行高度</strong>、<strong>低空飛行を実施する地点または地域</strong>、<strong>利用可能な不時着地点</strong>とそこまでの<strong>障害物件</strong>、<strong>人家の密集の程度</strong>を示す図 |
| <strong>89条</strong> | <strong>投下地点・投下地帯</strong>とその周辺の<strong>人家の密集の程度</strong>を示す図、（必要に応じて）物件の概要図 |

添付ファイルのルールは次のとおりです。

| ルール | 内容 |
|---|---|
| 形式 | <strong>jpg、jpeg、png、pdf</strong> |
| 数 | 1申請あたり<strong>5ファイルまで</strong> |
| 容量 | 1申請あたり<strong>合計80MBまで</strong>（複数の条文を同時に申請する場合も合計で） |
| ファイル名 | <strong>45文字まで</strong>。同じ名前のファイルは添付できない |

図面は1つずつ添付しても、<strong>まとめて1つのPDFにして</strong>添付してもかまいません。5ファイルの上限があるので、複数の場所を申請するときはPDFにまとめるのが現実的です。

### 途中で手を止めるとき

入力の途中で、たとえば登録していない操縦者がいることに気づいたら、<strong>申請を一時保存</strong>してから、事前登録の画面で追加します。各画面で「次へ」を押した時点の入力は一時的に保管されますが、画面の「戻る」で前の画面に戻ると、<strong>戻る前の画面で編集中だった内容は破棄</strong>されるので注意します。

## ④ 申請した後——ステータスと許可書

メインメニューの「<strong>申請情報一覧</strong>」で、手続の状況を確認できます。

| ステータス | 意味 |
|---|---|
| 下書き保存 | 一時保存した状態（未提出） |
| <strong>受付中</strong> | 受付待ち。<strong>この間だけ、自分で「引戻し」して修正できる</strong> |
| 手続内容確認中 | 受付が済み、内容を確認中 |
| 審査中 | 審査中 |
| <strong>補正対応</strong> | 補正指示が来た状態。内容を確認して修正し、再提出する |
| <strong>許可書発行済</strong> | 許可書が発行され、ダウンロードできる状態 |
| 手続完了 | 許可書をダウンロードした状態 |
| 受理完了 | （89条）届出が受理された状態 |
| 手続完了（期限切れ） | 許可期間が過ぎた状態 |

一覧では、飛行期間の終了日が<strong>1週間以内の申請は黄色</strong>、<strong>過ぎたものはグレー</strong>で表示されます。継続申請の出し忘れ防止に使えます。

送信中にパソコンが止まった場合は、一覧で「受付中」になっていれば送信は完了しています。「下書き保存」なら「編集」から提出し直し、一覧になければ申請し直します。

### 許可書のダウンロード

「申請情報一覧」で、ステータスが「<strong>許可書発行済</strong>」の申請を開き、「<strong>許可書ダウンロード</strong>」を押します。<strong>何度でも</strong>ダウンロードできます（2回目以降は「手続完了」で検索）。

許可書は<strong>ZIPファイル</strong>で、中身は次の3つです。

| ファイル | 中身 |
|---|---|
| <strong>xml</strong> | 押印の代わりに<strong>電子署名</strong>が付いた電子許可書 |
| xsl | xmlをブラウザで表示するための補助ファイル |
| <strong>pdf</strong> | 具体的な許可内容が書かれたファイル |

- <strong>オンライン申請に対して、紙の許可書は発行されません。</strong>
- 電子許可書には印影がありません。本物かどうかは、<strong>e-Gov電子申請システムの「公文書署名検証」</strong>で確認できます（ZIPを解凍してから）。

## ⑤ 2回目以降——継続・再申請、変更、複写

| 手続 | 使う場面 |
|---|---|
| <strong>継続申請</strong> | 過去に許可を受けた申請の飛行期間を、<strong>続けて延長</strong>する |
| <strong>再申請</strong> | 過去に許可を受けた申請を、<strong>間が空いた別の期間</strong>でもう一度出す |
| <strong>変更申請</strong> | 許可を受けた後に、<strong>内容を変更</strong>する。飛行終了日は元の許可と同じ日になる |
| <strong>新規申請</strong> | 過去に許可・届出の実績がない場所で行う。場所の追加・変更も新規から |
| <strong>複写</strong> | 過去の申請を引用して、新規申請を作る |

過去の申請との関係をはっきりさせるため、同じ内容をもう一度出すときは「新規」ではなく「<strong>継続申請／再申請</strong>」から出すよう求められています。継続申請・再申請では、飛行期間の更新とあわせて、元の内容を一部変更することもできます。

## 災害時

災害時に救援活動を行う場合は、<strong>電話（口頭）で申請・許可</strong>を受けることができます。その場合も、後日AOPSの「<strong>口頭許可後の手続き</strong>」から手続をします。

## 困ったとき

システム操作の専用ヘルプデスクはなく、まずはマニュアルとよくある質問を確認するよう案内されています。

| 内容 | 問い合わせ先 |
|---|---|
| システム全般 | 国土交通省航空局安全部安全政策課（03-5253-8737、平日9:00〜17:00） |
| 手続の内容 | 各申請先（[空港等以外の場所における離着陸の許可等に係る連絡先](https://www.mlit.go.jp/koku/koku_tk10_000058.html)） |
| パスワード・IDを忘れた | トップページの「パスワードがわからない場合」「ログインIDがわからない場合」から再設定・再通知 |

## まとめ

- AOPSは、<strong>79条（場外離着陸）・81条（低空飛行）・89条（物件投下）</strong>の申請・届出をオンラインで行い、<strong>電子許可書</strong>を受け取れるシステム。無料、24時間。<strong>Windows＋Edge</strong>が前提。
- まず<strong>アカウント</strong>を開設（個人／法人。マイナンバーカード・gBizIDは任意の入力補助）。
- 申請の前に、<strong>航空機・操縦者・同乗者（81条）・離着陸場所（79条）</strong>を事前登録しておく。申請画面では一覧から選ぶだけで、その場では追加できない。
- 新規申請は「条文と場所を選ぶ → 基本情報 → 条文ごとの情報と図面 → 操縦者・航空機・同乗者を選ぶ → 確認・提出」。<strong>「OK」を押した日が申請日</strong>。
- 添付は<strong>jpg・png・pdf、5ファイル・合計80MBまで</strong>。図面はPDFにまとめるのが現実的。
- 修正できるのは「<strong>受付中</strong>」のうちだけ（引戻し）。許可書は「<strong>許可書発行済</strong>」になったらZIPでダウンロード。<strong>紙の許可書は出ない</strong>。
- 2回目以降は<strong>継続申請・再申請</strong>や<strong>複写</strong>で。申請は許可が必要な日の<strong>1〜2週間前</strong>までに。
