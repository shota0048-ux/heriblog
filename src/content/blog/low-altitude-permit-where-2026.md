「低空の申請って、どこに出すんだっけ？」

最低安全高度以下の飛行許可（航空法第81条ただし書）の申請で、こう迷っている人がいました。実際、申請先は<strong>飛行の種類</strong>と<strong>場所</strong>の2つで決まり、組み合わせで4か所に分かれます。慣れていないと迷うのも無理はありません。

国土交通省の事務処理の基準と、最新の連絡先一覧から整理しました。

先に結論です。

- <strong>航空運送事業・IFR・夜間・物件のつり下げ等</strong> → <strong>東京航空局 または 大阪航空局</strong>（保安部 運航課）
- <strong>それ以外</strong>（多くの訓練・撮影・調査など） → <strong>東京空港事務所 または 関西空港事務所</strong>
- 東西の境目は、<strong>新潟県・長野県・静岡県から東が「東京」</strong>、<strong>富山県・岐阜県・愛知県から西が「大阪・関西」</strong>
- 場所が東西にまたがるときは、<strong>両方</strong>に出す

## そもそも、許可が必要な飛行か

航空法第81条は、離陸・着陸の場合を除いて、最低安全高度以下で飛ぶことを禁じています。最低安全高度は施行規則第174条で、VFRの場合は次のとおりです。

| 場所 | 最低安全高度 |
|---|---|
| 人または家屋の密集している地域 | 航空機を中心に水平距離600mの範囲内で、<strong>最も高い障害物の上端から300m</strong> |
| 人または家屋のない地域、広い水面 | 地上・水上の人または物件から<strong>150m以上の距離</strong>を保てる高度 |
| それ以外の地域 | <strong>地表面・水面から150m以上</strong> |

<small>いずれの場合も、「飛行中に動力装置だけが停止した場合に、地上・水上の人や物件に危険を及ぼすことなく着陸できる高度」のほうが高ければ、そちらが最低安全高度になります（施行規則第174条第1号）。</small>

これより低く飛ぶ必要がある場合に、81条ただし書の許可が要ります。

なお、<strong>国土交通省令で定める航空機（警察・消防・防衛などの公的機関の航空機や、その依頼を受けた航空機）が、事故や海難などで捜索・救助のために行う航行</strong>には、81条自体が適用されません（第81条の2）。この場合は申請不要です。

### 第1段階：飛行の種類で、地方航空局か空港事務所か

<strong>地方航空局（東京航空局・大阪航空局）</strong>に出すのは、次のいずれかに当たる飛行です。

- <strong>航空運送事業</strong>の用に供する航空機
- <strong>計器飛行方式</strong>により、または<strong>夜間</strong>において飛行しようとする航空機
- 物件を<strong>機体の外に装着し、つり下げ、または曳航</strong>して運送しようとする航空機

ヘリでいえば、<strong>夜間の低空飛行</strong>や<strong>スリング（つり下げ輸送）</strong>は地方航空局です。

<strong>それ以外</strong>、つまり昼間のVFRで、運送事業でもつり下げでもない飛行（訓練、撮影、調査、薬剤散布など）は、<strong>空港事務所</strong>に出します。

場所が日本の外（公海上など）の場合は、本省の<strong>航空局安全部安全政策課</strong>です。

### 第2段階：場所で、東か西か

2021年10月1日から、空港事務所あての申請先は<strong>東京空港事務所</strong>と<strong>関西空港事務所</strong>の2か所にまとめられています。地方航空局の管轄も同じ境目です。

| 低空飛行を行う場所 | 地方航空局あて | 空港事務所あて |
|---|---|---|
| 北海道、青森、岩手、宮城、秋田、山形、福島、茨城、栃木、群馬、埼玉、千葉、東京、神奈川、<strong>新潟、山梨、長野、静岡</strong> | <strong>東京航空局</strong> | <strong>東京空港事務所</strong> |
| <strong>富山、石川、福井、岐阜、愛知</strong>、三重、滋賀、京都、大阪、兵庫、奈良、和歌山、鳥取、島根、岡山、広島、山口、徳島、香川、愛媛、高知、福岡、佐賀、長崎、熊本、大分、宮崎、鹿児島、沖縄 | <strong>大阪航空局</strong> | <strong>関西空港事務所</strong> |

<strong>低空飛行を行う場所が東西にまたがる</strong>場合（たとえば静岡と愛知をまたぐ）は、<strong>両方に申請</strong>します。

## 何を出すか——申請書と図面

### 申請書の記載事項

申請書の様式は、空港事務所あてが「様式6-13」、地方航空局あてが「別添様式1」です。宛先が違うだけで、書く項目は同じです。

| 項目 | 書くこと |
|---|---|
| 申請者 | 氏名または名称、住所、法人の場合は代表者の氏名、連絡先 |
| 航空機 | 型式、国籍、登録記号 |
| 飛行計画の概要 | <strong>飛行の目的</strong>、<strong>日時</strong>、<strong>経路及び高度</strong> |
| 低空飛行をする理由 | なぜ最低安全高度以下で飛ぶ必要があるのか |
| 操縦者 | 氏名、資格（定期・事業用・自家用） |
| 同乗者 | 氏名、同乗の目的 |
| その他参考となる事項 | 必要に応じて |

### 添付する図面——ここがいちばん大事

「経路及び高度」の欄には、<strong>経路と高度を表示するほか、次の事項を記載した図面を添付すること</strong>と書かれています。

- <strong>経路上の飛行高度</strong>
- <strong>低空飛行を実施する地点または地域</strong>
- <strong>利用可能な不時着陸地点</strong>と、<strong>低空飛行実施場所からその不時着陸地点に至るまでの間の障害物件</strong>
- <strong>人または家屋の密集の程度</strong>

事務処理の基準でも、経路と高度を<strong>できるだけ具体的に</strong>書かせ、低空飛行実施場所、緊急時の不時着陸地点、そこまでの障害物件を<strong>図示した書面</strong>を添付させることになっています。

実務では、次の2種類を用意すると説明しやすくなります。

1. <strong>広域図</strong>——低空飛行の範囲、飛行経路、不時着陸地点を地図に示したもの
2. <strong>詳細図</strong>——低空飛行を行う場所の平面図と断面図。飛行高度の範囲、周囲の樹木・建物・電線などの障害物と、その高さ・距離

### 許可の基準——図面で何を示すのか

図面は、次の基準を満たしていることを示すためのものです。許可されるのは、すべてに適合する場合に限られます。

| 基準 | 内容 |
|---|---|
| ① 禁止される飛行でないこと | <strong>石油コンビナート地帯</strong>上空、<strong>原子力関係施設</strong>上空、<strong>重要文化財指定建造物</strong>上空、<strong>回転翼航空機による人または家屋の密集地域上空での高度400フィート以下・対気速度毎時30マイル以下</strong>の飛行でないこと |
| ② 必要やむを得ないこと | 特定の飛行目的を達成するために必要かつやむを得ないこと。薬剤散布、送電線監視、撮影、物件投下、捜索救助訓練、地勢調査などは低空が必要なことが多いが、作業方法や機材で低空が不要になる場合もあるので総合的に判断される |
| ③ 安全に不時着陸できる高度であること | 緊急時に地上・水上の人や物件に危険を与えずに不時着陸できる高度であること。<strong>滑空比、不時着陸地点までの距離、途中の障害物の位置と高さ、発動機の性能</strong>などから総合的に判断される |
| ④ 競技場などの主催者の承諾 | 競馬場や野球場などで競技の開催中に上空を低空飛行する場合は、主催者の承諾を得ていること |
| ⑤ 複数機の調整 | 多数の航空機が同じ場所で同時に低空飛行する（可能性がある）場合は、機体間の間隔、進入・旋回・離脱の方法を操縦士間で十分調整していること |
| ⑥ 人員のつり上げ・つり下げ | （地方航空局あてのみ）航空運送事業者・航空機使用事業者が人員のつり上げ・つり下げを伴う輸送を行う場合は、運航規程審査要領細則の要件に基づいて運航規程等を定め、それに従って運航すること |

<small>①〜⑤は空港事務所あて・地方航空局あての両方の基準に共通。⑥は地方航空局の事務処理基準（令和6年7月1日施行の改正）にある項目。</small>

<strong>③の「不時着陸できる高度」を、図面で説得力をもって示せるか</strong>が審査の中心です。不時着陸地点までの距離と、その間にある障害物の高さは、地図と断面図で具体的に示しておくと話が早くなります。

## 許可期間と、包括許可

| | 期間 |
|---|---|
| 原則 | <strong>15日以内</strong> |
| 包括許可（状況の変化が少ない場合） | <strong>3か月</strong>まで |
| 包括許可（その地域で6か月以上の許可実績があり、安全上の問題がない場合） | <strong>6か月</strong>まで |
| つり下げ輸送（地方航空局あて） | 運航規程等でつり下げ輸送の方法を定めている航空運送事業者・航空機使用事業者、または航空局長が適切と認めた運航マニュアルに従う官公庁・消防機関などは、<strong>1年</strong>まで |

包括許可の条件は、<strong>同じ目的で同じ地域を飛ぶこと</strong>、<strong>飛行前に申請時から状況が変わっていないことを確認すること</strong>、<strong>状況が変わったら速やかに報告して申請し直すこと</strong>、の3つです。

地方航空局あてでは、<strong>複数の場所での低空飛行を一括して申請</strong>することもできます。

## 許可をもらった後に変更が出たら

| 変更の内容 | 必要な手続 |
|---|---|
| <strong>航空機の型式</strong>、<strong>飛行計画の概要</strong>、<strong>低空飛行をする理由</strong> | 飛行の前までに、<strong>申請書と変更部分の添付書類を出し直して許可を受ける</strong> |
| それ以外（操縦者や同乗者の変更など） | 飛行の前までに、変更の内容を<strong>通知</strong>する |

申請先が複数にまたがる場合は、すべてに提出・通知します。

## 災害時の緊急の場合

回転翼航空機が、災害やそれに類する事態で緊急に支援活動をする必要がある場合は、<strong>電話で申請</strong>できます。氏名、使用機材、低空飛行の目的、実施する地点または地域、利用可能な不時着地点などを伝え、後で速やかに申請書を提出します。

非常災害対策本部や緊急災害対策本部が設置された場合などは、「災害時に救援活動を行う航空機に係る許可手続等に関する処理要領」に従い、やむを得なければ事後の連絡でもよいとされています。このときも、後日申請書を提出します。

緊急の申請は夜間・休日にも受け付けています。連絡先は上の表の時間外の番号です。

## あわせて確認したい手続

低空飛行と一緒に、次の手続が必要になることがよくあります。申請先の振り分けは81条と似ていますが、同じではありません。

- <strong>空港等以外の場所での離着陸（第79条ただし書）</strong>——地方航空局あては<strong>航空運送事業</strong>と<strong>構築物（船舶・構築物）での離着陸</strong>に限られ、それ以外は空港事務所です。
- <strong>物件投下の届出（第89条ただし書）</strong>——すべての航空機が<strong>空港事務所</strong>あてです。

## まとめ

- 最低安全高度以下で飛ぶには、<strong>航空法第81条ただし書の許可</strong>が必要。公的機関等の航空機による捜索・救助は<strong>第81条の2</strong>で適用除外。
- 申請先は<strong>2段階</strong>で決まる。<strong>航空運送事業・IFR・夜間・物件の機外装着／つり下げ／曳航</strong>なら<strong>地方航空局（東京・大阪航空局 保安部運航課）</strong>、それ以外は<strong>空港事務所（東京・関西空港事務所）</strong>。本邦外は<strong>航空局安全政策課</strong>。
- 東西の境目は、<strong>新潟・長野・静岡から東が東京</strong>、<strong>富山・岐阜・愛知から西が大阪・関西</strong>。場所がまたがる場合は<strong>両方</strong>に申請。
- 申請書には目的・日時・経路と高度・理由・操縦者などを書き、<strong>飛行高度、実施場所、不時着陸地点、そこまでの障害物件、人家の密集の程度を示した図面</strong>を添付する。
- 許可の中心は「<strong>安全に不時着陸できる高度か</strong>」。許可期間は原則<strong>15日</strong>、包括で<strong>3か月・6か月</strong>、つり下げ輸送は条件付きで<strong>1年</strong>。
- 手数料なし、標準処理期間は<strong>1〜2週間</strong>。提出方法は申請先に確認する。
