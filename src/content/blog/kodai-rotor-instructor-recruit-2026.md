8月に[航空大学校の教官募集は「飛行機」だけ](/blog/koudai-heli-instructor-2026/)という記事を書きました。そのときは、回転翼の教官募集はまだ出ていませんでした。

それが、<strong>令和8年11月19日付で出ました</strong>。「航空大学校回転翼航空機操縦教官（契約職員）の募集について」です。

しかも同じ日に、<strong>「航空大学校回転翼訓練機2機及びFTD1基の調達」の入札公告</strong>も出ています。人と機材が、同じ日に動き出したことになります。

## 募集の中身

まず、募集要項に書かれていることをそのまま整理します。

### 何のための募集か

要項の冒頭には、ドクターヘリや消防防災ヘリの操縦士の高齢化が進み、人材確保が課題になっていること、国交省航空局が関係省庁と対策をまとめ、その中に航空大学校での養成コースの設置が入ったことが書かれています。

そのうえで、<strong>養成コースのために必要なシラバスの作成等を含めた業務を担う</strong>操縦教官を募集する、としています。コースが始まる前の準備から関わる仕事です。

### 応募資格（4つすべてを満たすこと）

| 項目 | 内容 |
|---|---|
| 年齢 | 昭和42年4月2日以降に生まれた人 |
| 学歴 | 高校卒業以上、またはそれと同等 |
| 資格 | 回転翼航空機の<strong>事業用操縦士以上の技能証明（陸上多発タービン）</strong>、<strong>計器飛行証明</strong>、<strong>航空無線通信士</strong> |
| 経歴 | 回転翼航空機による<strong>機長として250時間以上</strong>。その中に、<strong>多発タービン機の機長30時間以上</strong>と<strong>計器飛行50時間以上</strong>を含むこと |
| 身体検査 | 有効な<strong>第一種</strong>航空身体検査証明 |

計器飛行の50時間には、模擬計器飛行も含められます。ただし「航空機に乗り組んで視野制限装置を使用して計器飛行の訓練をした飛行時間に限る」とされています。シミュレーターの時間は入りません。

### 日程と条件

| 項目 | 内容 |
|---|---|
| 締切 | <strong>令和8年12月18日（金）必着</strong>。宮崎本校の総務課へ郵送するか、直接持っていく |
| 一次選考 | 書類 |
| 二次選考 | 面接と<strong>FTDによる試験</strong>。<strong>令和9年2月上旬</strong>、東京23区内で行う予定。交通費は自分で負担 |
| 合否通知 | 2月中旬 |
| 採用日 | <strong>令和9年4月1日以降</strong>の、調整で決める日 |
| 配属・人数 | 宮崎本校、若干名 |
| その他 | 今勤めている会社などの<strong>同意書が必要</strong> |

提出書類は、履歴書、技能証明書と無線従事者免許証の写し、航空経歴書、身体検査証明書の写し、それに<strong>作文「理想の操縦教官像とこれからの乗員養成について」</strong>（自筆、400字以上1200字以内）です。

給与、待遇、契約期間は要項に書かれていません。問い合わせ先は航空大学校宮崎本校の総務課（0985-51-1211）です。

| 計器・教育証明 | <strong>計器飛行証明または操縦教育証明</strong>（事業用の場合） | <strong>計器飛行証明</strong>。操縦教育証明の記載はない |

## 並べて見えること

ここからは、要項を読んだ私の見方です。

### 1. 飛行経歴の要件があるのは、回転翼だけ

飛行機の募集には、飛行時間の要件がありません。技能証明と計器飛行証明（または教育証明）があれば応募できます。採用後に任用訓練と任用審査があるので、そこで見る、という作りです。

回転翼は、<strong>機長250時間、多発タービン機長30時間、計器50時間</strong>と、経験を数字で求めています。コースが始まる前に、シラバスを作るところから担う人を探しているので、即戦力を求めるのは自然だと思います。

数字そのものは、双発タービン機で計器飛行証明を持って飛んでいる人なら、多くが届く水準です。ドクターヘリや消防防災ヘリの機長なら、まず満たしているでしょう。

### 2. 「多発タービン」は、訓練機の姿を映しているのかもしれない

技能証明に「陸上多発タービン」を求めています。新しく入る訓練機が双発タービン機で、教官がその機長になれる必要があるから、と読むのが自然です。

ただし、<strong>入札公告には機種が書かれていません</strong>（「仕様書による」）。何が入るのかは、まだ分かりません。

### 3. 操縦教育証明を求めていない

飛行機の募集では、事業用の場合「計器飛行証明<strong>または操縦教育証明</strong>」でした。回転翼の募集には、操縦教育証明が出てきません。

このコースの対象は「<strong>すでにライセンスを持つ若手操縦士</strong>」です（6月19日の航空大学校の発表）。免許を取らせる課程ではなく、経験を積ませる課程なので、教育証明より、実際に双発タービン機を計器で飛ばしてきた経験を重く見た、という読み方ができます。

ヘリで操縦教育証明を持っている人は多くありません。これを必須にすると、応募できる人がかなり減ったはずです。

### 4. 年齢の線は、飛行機と同じ

年齢は、飛行機と同じ「昭和42年4月2日以降に生まれた人」です。採用日（令和9年4月1日以降）の時点で59歳以下の人、ということになります。

ここは、ヘリ特有の事情とぶつかります。[国交省の資料では、ドクターヘリ機長の36%が60代](/blog/heli-pilot-age-structure-2026/)です。経験の最も厚い層の3分の1が、この線の外にいます。

飛行機の募集では、この年齢の線が「満60歳未満なら正職員」という条件とつながっていました。回転翼の要項には正職員化の記載がないので、同じ線を引いた理由は要項からは読めません。

### 5. 同意書の問題は、残ったまま

8月の記事では、<strong>教官をどこから連れてくるのか</strong>が最大の論点だと書きました。応募資格を満たす人は、いま現場で機長をしている人です。

今回の募集も、<strong>今勤めている会社の同意書</strong>を求めています。関係省庁連絡会議のとりまとめは、運航者にも「教官派遣等」で協力を求めていますが、今回の募集は契約職員としての直接採用です。

送り出す会社から見れば、貴重な機長を手放す話になります。応募する人にとっては、ここがいちばんの関門になると思います。

## 同じ日の入札公告——訓練機2機とFTD1基

教官募集と同じ11月19日に、入札公告も出ています。

| 項目 | 内容 |
|---|---|
| 件名 | 航空大学校回転翼訓練機2機及びFTD1基の調達 |
| 納入場所 | 航空大学校 宮崎本校 |
| 機種・納入期限 | 仕様書による（公告には書かれていない） |
| 落札の決め方 | <strong>総合評価落札方式</strong>。技術点（150点）と価格点（100点）の合計で決める |
| 入札者 | 1者、または<strong>実機とFTDの2者による共同</strong>での入札も可 |
| 参加申請の期限 | 令和8年12月9日 17時 |
| 開札 | <strong>令和9年1月12日</strong> 14時、宮崎本校 |

2者での入札を認めている理由として、公告は、訓練機に対応するFTDを<strong>実機と同時期に導入する必要がある</strong>ことを挙げています。機体メーカーとシミュレーターメーカーが別の会社でも応札できるようにした、ということです。

もう一つ目を引くのが、意見招請（仕様についての意見を事前に募る手続き）を実施しない理由です。公告は、<strong>養成訓練を令和10年度から開始するためには</strong>、その期間を確保できないためと書いています。なお、仕様書の選定には外部有識者を含めた会議の意見を採用した、とも添えています。

### 夏の「基礎調査」から続いている

この入札には前段があります。航空大学校は令和8年7月に、二つの基礎調査を入札にかけていました。

| 件名 | 落札者 | 契約金額（税込） | 契約日 |
|---|---|---|---|
| 緊急輸送用ヘリコプター操縦士養成に係る訓練機及びシミュレータ等に関する基礎調査 | 株式会社Japan General Aviation Service | 13,992,000円 | 令和8年8月3日 |
| 緊急輸送用ヘリコプター操縦士養成に係る訓練拠点に関する基礎調査 | 株式会社日本空港コンサルタンツ | 10,670,000円 | 令和8年7月28日 |

夏に機材と拠点の調査を発注し、秋に機材の本調達と教官の募集に進んだ、という流れです。

## 時系列で並べる

| 時期 | 出来事 |
|---|---|
| 令和8年6月19日 | 国交省が操縦士確保策をとりまとめ。航空大学校がヘリ養成コースの設置を発表 |
| 令和8年7〜8月 | 訓練機・シミュレータと訓練拠点の基礎調査を契約 |
| 令和8年8月3日 | 飛行機の操縦教官の募集（回転翼はなし） |
| <strong>令和8年11月19日</strong> | <strong>回転翼の操縦教官の募集、訓練機2機とFTD1基の入札公告</strong> |
| 令和8年12月18日 | 教官募集の締切 |
| 令和9年1月12日 | 訓練機・FTDの開札 |
| 令和9年2月上旬 | 教官の二次選考（面接・FTD） |
| 令和9年4月1日以降 | 教官の採用 |
| 令和10年度 | 養成訓練の開始（入札公告）。とりまとめでは「令和10年度末を目途」に運用開始 |

教官は、採用されてから訓練開始まで、およそ1年半から2年あります。その間に、シラバスを作り、訓練機とFTDを受け入れ、自分たちの慣熟も済ませる、という仕事になるはずです。

## 飛ぶ側として

8月の記事を書いたとき、ヘリの教官は「そう遠くない時期に動くはず」と書きました。3か月半で、本当に動きました。しかも機材の入札と同じ日です。準備は、思っていたより速く進んでいる印象です。

応募を考える人に向けて、一つだけ。要項には給与も契約期間も書かれていません。飛行機の募集にあった「正職員にする」という記載もありません。家族や今の会社と話す前に、<strong>総務課に条件を確認しておく</strong>のがよいと思います。

作文の題は、飛行機と同じ「理想の操縦教官像とこれからの乗員養成について」です。ヘリでこの問いに答えるなら、「免許を取ったあと、経験を積む場所がない若手に、何を、どの順で渡すか」が中心になると思います。それは、このコースが生まれた理由そのものです。

## まとめ

- 航空大学校が<strong>令和8年11月19日</strong>付で、<strong>回転翼航空機の操縦教官（契約職員）</strong>の募集を出した。締切は<strong>12月18日必着</strong>、宮崎本校で若干名、採用は<strong>令和9年4月1日以降</strong>。
- 応募資格は、<strong>事業用以上（陸上多発タービン）</strong>、<strong>計器飛行証明</strong>、航空無線通信士、第一種身体検査、昭和42年4月2日以降の生まれ。経歴は<strong>機長250時間以上</strong>（多発タービン機長30時間、計器50時間を含む）。
- 8月の飛行機の募集と比べると、回転翼だけに<strong>飛行経歴の要件</strong>と<strong>シラバス作成</strong>の業務があり、<strong>操縦教育証明</strong>、<strong>雇用期間</strong>、<strong>正職員化</strong>の記載がない。
- 同じ日に<strong>回転翼訓練機2機とFTD1基</strong>の入札公告。総合評価方式で、実機とFTDの2者共同入札も可。開札は<strong>令和9年1月12日</strong>。公告は、養成訓練を<strong>令和10年度から</strong>始めるため意見招請を省くとしている。
- 年齢の線は飛行機と同じで、<strong>60代が36%を占めるドクターヘリ機長の層</strong>は外れる。会社の<strong>同意書</strong>が必要な点も、教官確保の難しさとして残る。
