訓練や試験飛行で**民間訓練試験空域**（以下、訓練空域）を使うときは、事前に<strong>航空交通管理センター（ATMセンター）</strong>へ「訓練試験等計画」（訓練計画）を出して、空域の使用の承認を受けなければなりません（AIP ENR 5.3）。

この訓練計画は電話・電子メール・郵送でも出せますが、国土交通省は**インターネットで出せるサービス**も用意しています。

👉 国土交通省「[民間訓練試験空域の使用調整等におけるインターネットの利用について](https://www.mlit.go.jp/koku/15_bf_000011.html)」

あまり知られていない仕組みなので、**実施要領**（令和6年9月24日改正）と **AIP ENR 5.3** をもとに、登録の方法と、訓練計画を出してから飛ぶまでの流れを整理しました。

---

## ① インターネットでできること

国土交通省のページには、次の3つが挙げられています。

1. **空域使用計画状況の確認**（どの空域が、いつ、どの高度で使われる予定か）
2. **訓練計画の提出**
3. **空域の使用に係る承認結果の受領**

仕組みとしては、ATMセンターの<strong>航空交通管理処理システム（TEAM）</strong>に、利用者側のパソコン（**空域管理ユーザー端末、「GA端末」**）からインターネットで接続する形です。取扱い時間は**24時間**です。

実施要領には、訓練計画のほかに「**特殊飛行等**」（写真撮影や航空測量のように、一定の高度帯を保って特定の区間を VFR で飛ぶもの）の情報を扱う機能も書かれています。ただし、こちらは「**ATMセンターから運用についての指示があるまで使用しない**」とされています。

## ② 登録の方法

インターネットを使うには、事前に**利用者として登録**する必要があります。

| 項目 | 内容 |
|---|---|
| **提出書類** | 「空域管理ユーザー申請書」と「空域管理ユーザー端末ID申請書」（国交省のページに様式と記入例あり） |
| **提出期限** | **利用開始希望日の45日前まで**（変更は30日前まで） |
| **対象** | **会社その他の団体のみ**。セキュリティの関係で、**個人の登録は受け付けない** |
| **審査・通知** | ATMセンターが審査し、「利用通知書」で利用開始日・端末ID・初期パスワードを通知 |
| **端末** | 端末ごとに端末IDを割り当て。会社コード（ICAOの3文字略号など）＋部門コード＋席コードで構成 |
| **代替部門** | 端末の障害時などに代わって調整できる部門を、申請書に書く欄がある |
| **費用** | 端末とインターネット接続は**利用者の負担** |

申請書の送付先・問い合わせ先は、ATMセンターの航空交通管理管制官事務室（インターネットユーザー登録担当、福岡市東区）です。電話番号・メールアドレスは国交省のページに載っています。

### パソコンの要件とセキュリティ

実施要領の別紙には、端末の**推奨要件**が書かれています。

- OS：Windows 10 Pro／11 Pro（64bit）を推奨
- CPU 3.2GHz×4 以上、メモリ 4GB 以上、27インチ 1920×1080 以上のディスプレイを推奨
- グラフィックは NVIDIA Quadro（メモリ2GB以上）を推奨

事務用のノートパソコンを想定した要件ではない、という印象です。最小要件はもう少し低く設定されています。

セキュリティ要件もあります。

- 航空局が指定する**証明書をインストール**する
- 関係者以外が操作できない場所に置く
- 初期パスワードは受け取ったら**8〜32文字**に変更し、**6か月を目安に更新**する
- USB などの外部媒体は、ウイルスがないことを確認してから使う

### 訓練計画が必要な飛行

訓練空域で次の飛行をするときは、**1飛行につき1通**の訓練計画が必要です。

- 技能証明の実地試験、耐空証明、無線局検査などのための試験飛行
- 試験飛行の前の社内試験飛行
- 訓練事業として行う訓練飛行
- その他、訓練空域を使う訓練飛行など（曲技飛行を含む）

ただし、**訓練空域の中にある飛行場等の場周経路に限った離着陸訓練**は、空域の通過として扱われ、訓練計画は要りません。

### 提出期限

| 場面 | 期限 |
|---|---|
| **原則** | **使用予定日（JST）の1週間前から、前日の12時（JST）まで** |
| **当日** | 使用計画を確認して空いている場合に限り、**出発予定時刻の1時間前まで** |
| 技能証明試験・耐空証明試験・無線局検査 | ATMセンターと調整すれば、1週間より前でも出せる |

提出すると**受付番号**を受け取ります。変更は原則として前日12時（JST）まで、当日は出発予定の1時間前までです。飛行中に担当の管制・通信機関を通じて変更を伝えることもできます。

### 調整と優先順位

同じ時間帯の同じ空域は、**原則1機**です。重なった場合は、ATMセンターから時間帯や高度帯の調整があります。内容が違う場合は、次の順に優先されます。

| 順位 | 内容 |
|---|---|
| 1 | 技能証明試験・耐空証明試験・無線局検査 |
| 2 | 社内試験 |
| 3 | 訓練 |
| 4 | その他 |

また、1機による1空域の使用は、原則として**連続2時間まで**です。

### 使用計画書の受け取り

承認の結果は「**使用計画書**」として受け取ります。

- 前日：**16時（JST）以降**に、受付番号で照会
- 当日：**飛行計画を出す前**に照会

使用計画書には**調整番号**が入っています。インターネットのサービスで受け取ることもできます。

### 飛行計画への記載

| 項目 | 書くこと | 例 |
|---|---|---|
| **第15項** | 空域名 | `KK4.1` |
| **第18項** | 担当の管制・通信機関の名称、周波数、調整番号 | `NOTE=CTC=OSAKA INFO 135.6MHZ ASM=A12345` |

（例は AIP ENR 5.3 のもの）

### 飛行中

訓練機は、担当の **Controlling Facility または Communication Facility** に連絡し、**訓練空域の入出域時刻を通報**して、**常に情報を聴取**します。

> 例「00 時 00 分、TH12-1 に入域します。」（AIP ENR 5.3）

訓練空域の中でも、**公示された待機経路や航空路の周り**は IFR 機が飛ぶ空域です。IFR 機の情報が入ったら、その空域は訓練に使えず、使用中なら速やかに離脱するなどの措置をとります。雷雲を避ける IFR 機を通すために、訓練の**一時中断を求められる**こともあります。

## ④ 間違えやすいところ

実際に計画を出すときに引っかかりそうな点です。

### 「実施日」は UTC の日付、締切は JST

訓練計画の時刻は**すべて UTC** です。そして「訓練／試験実施日」は、**空域に入る予定の UTC の日付**です。AIP の例では、

> 21日 2300UTC に入域予定の場合の訓練／試験実施日は 21 日

とされています。21日 2300UTC は**日本時間では22日の朝8時**です。一方、提出期限（前日12時）や使用計画書の受け取り（前日16時）は **JST** で決まっています。

**朝9時前（JST）に入る計画では、UTC の日付が前日になる**——ここは毎回確認したほうがよいと思います。

### FL290 以上は許可の申請も兼ねる

FL290 以上の空域に係る訓練計画の提出と承認には、**航空法第94条の2第1項ただし書の申請と許可が含まれる**とされています。

### 通過するだけの VFR 機も確認が必要

訓練をしない VFR 機が訓練空域を**通過する**場合も、飛行前に ATMセンターまたは空港事務所等で**空域の使用状況を確認**し、原則として担当の管制・通信機関に連絡する必要があります。

### 見張り義務はなくならない

訓練空域の承認を受けていても、航空法第71条の2（**見張り義務**）は免除されません。AIP は、ストロボライトやランディングライトの点灯も推奨しています（装備していて運航上支障がない場合）。

## ヘリの運航者にとって

ここからは私の考えです。

ヘリの会社では、**型式限定や技能証明の訓練・試験**、**整備後の社内試験飛行**、**耐空証明の検査飛行**などで訓練空域を使う機会があります。いずれも訓練計画が必要な飛行です。

電話で出す場合、使用状況の確認、提出、受付番号、前日16時以降の照会と、ATMセンターとのやり取りが何回か発生します。**インターネットなら空いている空域を見ながら計画を組め**、承認結果も画面で受け取れるので、訓練の多い会社ほど登録の価値はあると思います。

一方で、**登録は会社単位**で、**45日前までの申請**が必要です。必要になってから慌てないよう、訓練の計画を立てる担当部署で、事前に手続きを済ませておくのがよさそうです。

## まとめ

| 項目 | 内容 |
|---|---|
| **何ができる** | 空域の使用計画状況の確認、訓練計画の提出、承認結果（使用計画書）の受領 |
| **誰が使える** | ATMセンターに登録した**会社・団体**（個人は不可） |
| **登録** | 利用開始希望日の**45日前まで**に申請書2種を提出 |
| **電話・メール** | ネットを使わなくても、電話・電子メール・郵送で提出可能 |
| **提出期限** | 使用予定日の**1週間前〜前日12時（JST）**。当日は出発1時間前まで（空きがあれば） |
| **受領** | 前日**16時（JST）以降**。当日は飛行計画の前 |
| **時刻** | 計画は**UTC**。実施日は入域の UTC 日付 |
| **飛行中** | 入出域時刻を通報し、常時聴取 |
