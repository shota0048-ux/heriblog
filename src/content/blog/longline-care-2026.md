荷つりや消火バケットで使う<strong>ロングライン</strong>。機体の点検はしっかりやっていても、ロングラインやロープは「見た目で大丈夫そうなら使う」になっていないでしょうか。

Vertical誌が、2026年10月23日に「What lies beneath: Caring for helicopter utility and firefighting equipment（見えない内部で——ヘリのユーティリティ・消防機材の手入れ）」という記事を掲載しました。カナダ・ケロウナで開かれた整備関係の会議（Vertical MRO Conference）で、外部吊り下げ機材のメーカー <strong>Emergco</strong> のジェイソン・サイモン氏が行った実演を紹介したものです。

記事の内容を、日本語で要約して紹介します（全文の翻訳ではありません）。

先に結論です。

- 合成繊維のロープは、<strong>熱・紫外線・汚れ・水分・摩耗・繰り返し荷重</strong>で傷む。いくつも重なると劣化が早まる
- <strong>ロープの内部では、繊維どうしの摩擦で熱が出ている</strong>
- 実験では、<strong>8年使ったロングラインは新品時より約1割強く</strong>、<strong>カバーのない別のロープは強度が半分以下</strong>になっていた
- だから、<strong>「何年使ったか」より「どういう状態か」</strong>で判断する

---

## ロープを傷める6つの要因

記事は、合成繊維のロープを劣化させる要因として、次の6つを挙げています。

| 要因 | |
|---|---|
| 熱 | 外気の暑さだけでなく、ロープ内部の摩擦熱も |
| 紫外線 | 日光にさらされる時間 |
| 泥・汚れ | 繊維の間に入り込む |
| 水分 | |
| 摩耗 | 地面や物との擦れ |
| 繰り返し荷重 | 吊っては下ろす、の繰り返し |

どれも単独でロープの寿命を縮めますが、<strong>重なると影響が大きくなる</strong>、というのがポイントです。

## ロープの中は、思った以上に熱くなる

記事が特に強調しているのが、<strong>ロープ内部の熱</strong>です。

荷重がかかるたびに、ロープの中では繊維どうしが擦れ合います。記事によると、2021年の研究では、糸どうしの摩耗で<strong>約60℃</strong>に達したとされています。一方、合成繊維の中には<strong>約80〜90℃</strong>で性能が落ち始める臨界温度に近づくものがあります。

夏の消火活動では、外気の暑さに加えて、灰や泥などの汚れも入り込みます。<strong>内部の摩擦熱と外の熱、そして汚れが重なる</strong>ので、劣化のリスクが高くなります。

## 実験：古いロープが強く、別のロープが弱かった

実演では、2本のロープを引っ張って壊す試験の結果が示されました。

| | ロープA | ロープB |
|---|---|---|
| 状態 | <strong>8年使用</strong>の合成繊維ロングライン、外側にカバーあり | 直径7/16インチのロープ、<strong>カバーなし</strong> |
| 元の強度 | 約38,000ポンド（約17,200kg） | 約21,000ポンド（約9,500kg） |
| 試験方法 | 50フィート（約15m）の区間に10回荷重をかけてから、壊れるまで引っ張る | 記事に記載なし |
| <strong>壊れたときの強度</strong> | <strong>約42,000ポンド（約19,000kg）</strong>——元の強度より<strong>約1割高い</strong> | <strong>10,000ポンド（約4,500kg）未満</strong>——元の<strong>半分以下</strong> |

8年使ったロープAのほうが、新品時の強度を上回っていました。記事の説明では、高性能な繊維の中には、繰り返し荷重を受けることで繊維がなじんで荷重を均等に分け合うようになり、強度が上がるものがあるそうです。

一方で、カバーのないロープBは、強度が半分以下に落ちていました。

記事の結論は、<strong>年数よりも状態が大事</strong>、というものです。古いから危ない、新しいから安全、とは限りません。

## カバーの汚れは、中身の傷みとは限らない

点検でつい判断材料にしてしまうのが、外側のカバーの汚れや擦れです。記事は、次の点に注意を促しています。

- <strong>カバーが汚れていたり擦れていたりしても、中で荷重を受けている繊維が傷んでいるとは限らない</strong>
- カバーには、<strong>中の繊維を異物から守る役割</strong>もある

ロープAが8年使っても強度を保っていたことと、カバーのないロープBが大きく弱っていたことを並べると、カバーが中身を守っていたことがうかがえます（ここは私の読み方です。記事は2本の違いの理由をすべて説明しているわけではありません）。

## 点検で見るところ

記事が挙げている点検のポイントです。

| 項目 | 内容 |
|---|---|
| <strong>メーカーの指針に従う</strong> | 点検の基準はメーカーが示すもの |
| <strong>清潔に保ち、守る</strong> | 汚れや摩耗を減らす |
| <strong>使った履歴を知る</strong> | 過酷な消火・ユーティリティ作業のあとは、<strong>見た目の傷が小さくても詳しく点検</strong>する |
| <strong>見る場所</strong> | ロングライン本体、<strong>スプライス（つなぎ目）</strong>、<strong>金具</strong> |
| <strong>危ないサイン</strong> | 局所的な<strong>膨らみ</strong>、<strong>縫い目の傷み</strong>、普通と違う摩耗、<strong>一か所に集中した摩耗</strong> |
| <strong>壊れやすい場所</strong> | カバーの留め具（ジッパーや面ファスナー）そのものより、<strong>留め具を縫い付けている縫い目</strong>で壊れることが多い |
| <strong>交換時期</strong> | 使い方次第で、何年も使えることもあれば、早めの交換が必要なこともある |

なお、記事には点検の間隔や保管方法、規則・認証への言及はありませんでした。具体的な点検間隔や廃棄基準は、使っている機材のメーカーの指示と、会社の整備規程に従うことになります。

## 日本の運航に引きつけると

日本でも、荷つり（物資輸送、建設資材、送電線工事など）や、防災ヘリ・自衛隊ヘリの空中消火でロングラインが使われています。読んでいて、現場で意識しておきたいと感じたのは次の点です。

- <strong>「何年目か」だけで判断しない</strong>。使った量と使い方（消火か、荷つりか、夏か）を記録しておくと、点検の判断材料になる
- <strong>夏の消火活動のあと</strong>は、見た目がきれいでも詳しく見る。内部は熱と汚れにさらされている
- <strong>スプライスと金具、縫い目</strong>を重点的に。カバーの汚れだけで判断しない
- <strong>膨らみや一か所に集中した摩耗</strong>は、中の繊維の傷みのサインかもしれない

吊り下げ物件の落下は、地上の人や物に直接つながります。[尾瀬の荷つり作業での事故](/blog/bell212-sling-load-ground-injury-2026/)や、[吊下物件の落下の扱いの変更](/blog/serious-incident-sling-tsunami-2026/)でも書いたように、地上の安全に直結する機材です。「機体の一部」と同じ目で見ておきたいところです。

## まとめ

- Vertical誌（2026年10月23日）が、外部吊り下げ機材メーカーEmergcoによるロングラインの手入れの実演を紹介した。
- 合成繊維のロープは、<strong>熱・紫外線・汚れ・水分・摩耗・繰り返し荷重</strong>で傷み、重なると劣化が早まる。<strong>内部の摩擦熱は約60℃</strong>に達し、繊維によっては<strong>80〜90℃</strong>で性能が落ち始める。
- 実験では、<strong>8年使ったカバー付きのロングラインが新品時より約1割強く</strong>、<strong>カバーのないロープは強度が半分以下</strong>だった。<strong>年数より状態</strong>で判断する。
- カバーの汚れは中身の傷みとは限らず、カバーは中の繊維を守っている。
- 点検は、<strong>メーカーの指針</strong>に従い、<strong>本体・スプライス・金具・縫い目</strong>を重点的に。<strong>膨らみや集中した摩耗</strong>に注意。過酷な作業のあとは詳しく見る。
