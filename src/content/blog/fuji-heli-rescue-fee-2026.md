2026年9月14日、山梨県が富士山の閉山期対策をまとめました。**閉山期に防災ヘリで救助された場合、原則有料**にするという内容です。

これを見て、条文の側が気になりました。<strong>「救助した対価として金を取る」とは、実は書けないはずだ</strong>からです。

調べてみると、名目は**手数料**でした。しかも「救助の手数料」ではなく、<strong>飛行にかかった燃料の実費相当額</strong>という建て付けです。なぜそんな回りくどい形になるのか。そして、その金額はどう決まっているのか。

以前[「救助はタダ」でいいのか](/blog/mountain-rescue-paid-debate-2026/)という記事を書きましたが、今回は<strong>是非の判断はしません</strong>。制度がどう組み立てられているかと、有料化が行動に何を起こすかの材料だけを並べます。

---

## 山梨県の制度案（2026年9月14日）

まず報じられている内容から。

| 項目 | 内容 |
|---|---|
| 対象 | **閉山期**の富士山で遭難し、**県の防災ヘリ**で救助された場合 |
| 原則 | <strong>有料</strong> |
| 減免 | **登山届を提出し、適切な安全対策を講じていた**登山者は減免 |
| 減免の判断 | 装備・計画・保険が県の定める基準を満たすか、**届け出の内容に沿って行動したか**などの客観的事実に、専門家の知見を加えて判断 |
| 新制度 | <strong>「富士登山届出制度」</strong>を創設。閉山期に**6合目以上**へ登る場合は登山届の提出を義務化 |
| 金額 | <strong>5分あたり8,000円程度</strong>を徴収する案 |
| 時期 | <strong>2027年9月</strong>の閉山後からの運用開始を目指し、条例化などの準備を進める |

設計として押さえておきたいのは、<strong>「違反したら有料」ではなく「原則有料、要件を満たせば減免」</strong>という向きになっている点です。**デフォルトが有料**で、届出と装備と計画が揃っていれば引かれる。順番が逆だと、制度の意味がかなり変わります。

長崎幸太郎知事は同日の定例記者会見で、閉山中の登山について「安易なレジャー感覚をやめてもらいたい」と述べたと報じられています。

なお静岡県は、**登山届の義務化と未提出へのペナルティ**を検討する一方、<strong>ヘリ救助の有料化は当面見送り</strong>としています。理由として挙げているのが「**県警との公平性**」と「**地上隊による救助が大部分**」。ただし「現時点でやらないと決めたわけではない」とも説明しています。両県は6月からワーキンググループで協議していますが、根拠となる法令や制度が県ごとに違うため、足並みはそろっていません。

## なぜ「手数料」なのか——2つの壁

### 壁①：消防組織法

消防組織法は、まず消防の任務をこう定めています。

> **第一条**（消防の任務）　消防は、その施設及び人員を活用して、国民の生命、身体及び財産を火災から保護するとともに、水火災又は地震等の災害を防除し、及びこれらの災害による被害を軽減するほか、災害等による傷病者の搬送を適切に行うことを任務とする。

そして費用について、こうあります。

> **第八条**（市町村の消防に要する費用）　市町村の消防に要する費用は、当該市町村がこれを負担しなければならない。

条文が名指ししているのは市町村で、都道府県の防災航空隊はそれを応援する立場です。とはいえ<strong>「消防に要する費用は公費で負担する」という原則</strong>が制度全体の前提に置かれていることに変わりはありません。山岳遭難の救助はこの「消防」の中に入ります。

つまり、<strong>救助というサービスそのものの対価としては請求できない</strong>という壁が最初にあります。

### 壁②：航空法

もうひとつが航空法です。

> **第二条第十八項**　この法律において「航空運送事業」とは、**他人の需要に応じ、航空機を使用して有償で旅客又は貨物を運送する事業**をいう。

> **第百条**（許可）　航空運送事業を経営しようとする者は、国土交通大臣の許可を受けなければならない。

要素は3つです。**①他人の需要に応じ ②有償で ③旅客を運送する**。

遭難者を乗せて飛び、その運送に対してお金を取る——という形にすると、この3つが揃ってしまうおそれがある。国土交通省の担当者も「**航空法が定める事業にあたる可能性がある**」と指摘していると報じられています。もしそうなれば、防災ヘリは自家用の枠では飛べなくなり、許可や事業計画、運航規程といった手続きが必要になります。

<strong>「救助の対価」でもダメ、「運送の対価」でもダメ。</strong>この2つを同時にかわす必要がありました。

### 抜け道としての「手数料」

そこで使われたのが、地方自治法の手数料規定です。

> **第二百二十七条**（手数料）　普通地方公共団体は、当該普通地方公共団体の事務で**特定の者のためにするもの**につき、手数料を徴収することができる。

> **第二百二十八条**　分担金、使用料、加入金及び手数料に関する事項については、**条例でこれを定めなければならない**。

整理するとこうなります。

- 救助という**役務の対価**ではない
- 旅客を**運送した対価**でもない
- <strong>「特定の者のために飛行した、その燃料の実費相当額」を手数料として徴収する</strong>

この形なら、消防組織法の費用負担原則にも、航空法の事業性にも正面からぶつからない。だから**条例を作って、知事が告示で額を定める**という手順を踏むわけです。

ここが、今回のいちばんの肝だと思います。<strong>金額の水準ではなく、金額の「性格」が制度を成立させている。</strong>

## 先行例——埼玉県（2018年1月〜）

全国で唯一、実際に運用しているのが埼玉県です。

| 項目 | 内容 |
|---|---|
| 条例 | **埼玉県防災航空隊の緊急運航業務に関する条例** |
| 施行 | **平成30年（2018年）1月1日** |
| 金額 | 飛行時間<strong>5分ごとに8,000円</strong>（令和6年〈2024年〉4月1日改定。それ以前は**5,000円**） |
| 額の決め方 | **知事が告示で定める** |
| 性格 | <strong>実績値から算出した燃料費相当分</strong> |
| 飛行時間 | <strong>防災航空センター（川島町）の離陸時刻から、医療機関への搬送完了時刻まで</strong> |
| 対象区域 | 県内の**6山域**（小鹿野二子山、両神山、甲武信ヶ岳、日和田山、笠取山、雲取山） |
| 適用除外 | 林業・有害鳥獣捕獲・建設業などの**業務従事者**、人命救助者、**山小屋運営者**、環境保護活動従事者、**学校教育活動の参加者**など |
| 減免 | **地震等の自然災害が原因**の遭難者、**生活保護受給者** |

過去の平均救助時間が約1時間とされているので、目安としては**当初が約6万円、現在は約9.6万円**ということになります。

細かいところですが、<strong>飛行時間の起算が「基地の離陸」から</strong>という点は見落としやすいところです。現場上空にいた時間ではなく、**出て戻るまで**が計算に入ります。山が遠ければ、それだけ額は積み上がります。富士山で同じ単価を適用した場合に総額が膨らみやすいのは、このためです。

適用除外の並びも、読むと制度の意図が見えます。**林業・建設業・山小屋・学校教育**——つまり<strong>「そこで働いている人」と「教育活動」は外す</strong>。狙いを娯楽としての登山に絞っている、という設計が読み取れます。

## 8,000円という金額の根拠

県の説明は<strong>「実績値から算出した燃料費相当分」</strong>です。改定理由は、要するに**航空燃料の値上がり**です。

1時間あたりに直すと、こうなります。

| | 5分あたり | 1時間あたり |
|---|---|---|
| 2018年1月〜 | 5,000円 | **60,000円** |
| 2024年4月〜 | **8,000円** | <strong>96,000円</strong> |

**1.6倍**です。2017年ごろから2024年にかけての航空燃料価格の動きを考えると、水準としては素直な改定に見えます。

### 試算してみる

ここからは筆者の**試算**です（県が単価を公表しているわけではありません）。

埼玉県防災航空隊は現在、**AW139を3機**運用しています。1時間96,000円が燃料費相当だとして、仮にJet A-1の調達単価を1リットル200円とすると、

> 96,000円 ÷ 200円/L = **480 L/h**

AW139クラスの巡航時燃料流量として、おおむね違和感のない数字です。逆に、この桁がまったく合わないということもない。**「燃料代」という説明は、数字の上でも一応筋が通っている**と言えそうです。

### 入っていないもの

重要なのは、この手数料に<strong>何が入っていないか</strong>のほうです。

- **操縦士・整備士・隊員の人件費**
- **機体の減価償却**
- **整備費・部品費**
- **格納庫と基地の維持費**
- <strong>待機している時間のコスト</strong>

防災ヘリの本当のコストは、飛んでいる時間ではなく<strong>飛んでいない時間に積み上がる</strong>ものが大半です。人も機体も、出動がなくても常に用意しておかなければ意味がない。

それでも燃料費だけに絞っているのは、地方自治法227条の「手数料」が<strong>実費を超えて取れない</strong>建て付けだからです。総コストを丸ごと請求すれば、それはもう手数料ではなく**運送の対価**に近づいてしまい、航空法の議論に踏み込むことになる。

<strong>誰が見ても実費とわかる項目に限定することで、条例の説明が立つ。</strong>金額が「安い」のではなく、**安くしないと制度が成り立たない**という構造です。

なお、富士山の**入山料4,000円**は通行料・保全協力金であって、この手数料とはまったく別の枠組みです（2025年から全4ルート共通、事前Web予約が必要）。

## 「無料だと荒れる」のか

ここからは法律の話を離れて、行動の側です。有料化の議論では必ずここが争点になります。

### 「無料だと荒れる」側の説明

よく挙げられるのは4つです。

| 考え方 | 内容 |
|---|---|
| **モラルハザード** | 失敗のコストを自分が負わないと、事前の注意が減る。保険の基本問題と同じ構造 |
| **コモンズの悲劇** | 誰でもタダで使える共有資源は過剰利用される。防災ヘリの稼働枠は有限の共有資源 |
| **リスク補償（ペルツマン効果）** | 安全装置が整うほど行動が大胆になる。「ヘリが来るから」で軽装・弾丸登山に踏み切る心理 |
| **割れ窓理論** | 小さな無秩序を放置すると大きな無秩序を招く。ただし実証面では評価が割れている |

国内で分かりやすい実例が、三重県松阪市です。

**2024年6月から、市内3病院（済生会松阪総合病院・松阪中央総合病院・松阪市民病院）で、救急車で運ばれたが入院に至らなかった軽症者に「選定療養費」7,700円を求める運用**を始めました。導入後8月末までの3か月で、**救急搬送件数が前年同期比で約2割（23%）減**、**1日50件以上出動する日が8割減**したと報じられています。市民3,000人への意識調査では、徴収への賛同が<strong>77.6%</strong>でした。

### ところが、逆向きの証拠もある

有名なのが、Gneezy と Rustichini の <strong>"A Fine is a Price"</strong>（Journal of Legal Studies, 2000）です。

イスラエル・ハイファの保育園**10園**を対象に、20週間の実験を行いました。5週目から**6園で「お迎えの遅刻に罰金」を導入**し、残り4園を対照群としました。

結果は直感に反するものでした。

> <strong>罰金を導入した園では、遅刻が有意に増えた。</strong>しかも、**罰金を撤廃したあとも遅刻は元に戻らなかった。**

解釈はこうです。罰金が導入される前、遅刻は「先生に申し訳ないこと」でした。罰金が付いた瞬間、それは<strong>「お金を払えば買える延長サービス」</strong>に変わった。道徳的な義務が、価格に置き換えられて**消えてしまった**（クラウディング・アウト）。そして一度価格になったものは、価格をなくしても義務には戻らなかった。

献血を有償にすると提供者が減る、という議論も同じ系統です。

### 山岳救助に引きつけると

この副作用は、2つの形で出るとされています。

1. <strong>免罪符化</strong>——「払う覚悟があるなら何をしてもいい」
2. <strong>要請の躊躇</strong>——請求を恐れて通報が遅れ、**重篤化・夜間化**する

有料化の課題として行政側が挙げているのは、主に2のほうです。

そして松阪の23%減についても、<strong>料金そのものの効果なのか、制度導入が大きく報道されたアナウンス効果なのかは切り分けられていません</strong>。「無料か有料か」よりも、<strong>「見られている・記録される」ことのほうが効いている</strong>可能性がある。

その意味では、山梨県の案が**金額と同時に登山届の義務化を抱き合わせている**のは、少なくとも設計として筋が通っています。どちらが効いたかは、あとから見ても分けられないでしょうが。

## 飛ぶ側から見ると

最後に、運航する側の視点で3つだけ。

### 手数料の有無は、飛ぶかどうかを変えない

当然ですが、<strong>「この人からは取れるから飛ぶ」「取れないから飛ばない」という判断はありません。</strong>要請があって、気象と機体と時間が成立すれば飛ぶ。有料化は**運航判断の外側**にある話です。

### 効くとすれば、要請が遅れること

副作用2のほうは、運航側に直接跳ね返ります。

請求を恐れて通報が遅れると、**日没に近づき、天候が崩れ、視程が落ちる**。同じ場所の同じ人を救うのに、<strong>2時間遅れるだけで難易度が別物になる</strong>のが山岳です。[群馬県防災ヘリの事故](/blog/gunma-haruna-lessons-2026/)のような事例を思い出すまでもなく、**条件の悪い時間帯に押し込まれること自体がリスク**です。

金額の設計より、**「早く呼んでいい」というメッセージが同時に出るかどうか**のほうが、現場には効きます。

### 届出義務化は、運航側にはありがたい

一方で、**登山届の義務化**は運航側にはっきり効きます。

- **どこに、何人で、どのルートで入ったか**が事前に分かる
- **装備と計画**が分かるので、生存可能性の見積もりが立つ
- 捜索範囲を絞れる＝<strong>飛行時間が短くなる</strong>

皮肉な話ですが、届出が徹底されれば**飛行時間が減り、結果として手数料の額も下がる**方向に働きます。山梨県の案が届出制度と減免をセットにしているのは、この点でも噛み合っています。

## まとめ

- 山梨県は2026年9月14日、<strong>閉山期の富士山で防災ヘリ救助を原則有料</strong>とする制度案を公表。**登山届を提出し適切な安全対策を講じていれば減免**。**6合目以上**への登山届提出を義務化する「富士登山届出制度」を創設し、<strong>2027年9月</strong>の運用開始を目指す。**5分8,000円程度**を徴収する案。
- 静岡県は**登山届の義務化＋ペナルティ**を検討する一方、**ヘリ有料化は当面見送り**（県警との公平性、地上隊救助が大部分）。
- 名目は<strong>「救助の対価」ではなく「飛行にかかった燃料の実費相当額の手数料」</strong>。**地方自治法第227条・第228条**を根拠に、条例と知事の告示で定める。
- この形を取るのは2つの壁を避けるため。**消防組織法**（第1条で山岳救助を含む消防の任務、第8条で費用の公費負担）と、**航空法**（第2条第18項の「有償で旅客を運送する事業」＋第100条の許可）。
- 先行例は**埼玉県**（2018年1月1日施行、全国唯一）。**6山域**限定、**飛行時間5分ごとに8,000円**（2024年4月に5,000円から改定）。飛行時間は<strong>基地の離陸から医療機関への搬送完了まで</strong>。
- 8,000円は<strong>実績値から算出した燃料費相当</strong>。1時間換算で**9.6万円**（改定前は6万円）。<strong>人件費・整備費・減価償却・待機コストは一切入っていない。</strong>手数料は実費を超えて取れないため、燃料費に絞らざるを得ない。
- 入山料4,000円は**通行料・保全協力金**で、この手数料とは別枠。
- 有料化が行動に効くという証拠：**松阪市**の選定療養費7,700円で救急搬送が3か月で**約2割（23%）減**。
- 逆向きの証拠：<strong>"A Fine is a Price"</strong>（2000年、ハイファの保育園10園）。<strong>罰金導入で遅刻がむしろ増え、撤廃後も戻らなかった。</strong>道徳的義務が価格に置き換わって消えた。
- 山岳救助での副作用は<strong>①免罪符化 ②要請の躊躇</strong>。行政が課題として挙げるのは主に②。
- 松阪の効果も、**料金そのものかアナウンス効果か切り分けられていない**。「有料か無料か」より<strong>「見られている・記録される」ことのほうが効いている可能性</strong>がある。
- 運航側から見ると、**有料化は運航判断を変えない**。効くのは**要請の遅れ**（＝夜間化・悪天化）と、**届出義務化による捜索範囲の絞り込み**のほう。
