国土交通省航空局が2023年8月に出した「<strong>小型航空機用FDM導入ガイドライン</strong>」は、全32ページあります。取り付け、電波、データの取り扱い、活用方法まで幅広く書かれていて、読み終えても「結局、うちは何をすればいいのか」が掴みにくい資料です。

そこで、<strong>どんなFDMなら最低限よいのか</strong>という目線で整理し直しました。

先に結論です。

- ガイドラインは<strong>義務ではなく推奨</strong>。本文にも「<strong>音声や映像のみの記録でも十分に有効</strong>」とある
- 最低限なら、<strong>市販のアクションカメラかスマホで、計器盤と（できれば）音声を記録する</strong>だけで成り立つ
- 条件は、<strong>機体を改造しないこと</strong>と、<strong>電波を出す使い方をするならEMC試験をして書類を残すこと</strong>
- これから機器を選ぶなら、<strong>ATC音声が録れて、4Hz・フルHD以上、電源連動で約10時間分を上書き保存</strong>できるものが目安

---

## FDMとは、何を指しているか

<strong>FDM（Flight Data Monitoring）</strong>は、ICAOの定義では「運航の安全性を向上させるために、記録した飛行データを分析するプロセス」です。機械そのものではなく、<strong>記録して振り返る仕組み</strong>のことです。

ガイドラインは、そのための機器（FDM機器）を3種類に分けています。

| 種類 | 中身 | 例 |
|---|---|---|
| <strong>FDM機能（組み込み型）</strong> | グラスコクピットなどに備わっているデータ記録機能 | アビオニクスのデータログ |
| <strong>FDM機器（一般）</strong> | 航空用に開発・製造されたFDM機器 | Vision1000など |
| <strong>FDM機器（さらなる簡易型）</strong> | 汎用品だが、FDMの用途に使える機器 | アクションカメラ、スマートフォン |

大型機に義務付けられている<strong>FDR</strong>（耐衝撃・耐火・耐水を備えたフライトレコーダー）とは、明確に別のものとして扱われています。

### 搭載が推奨される機体

- 最大離陸重量<strong>5.7t以下の飛行機</strong>と<strong>回転翼航空機</strong>のうち、飛行記録装置の搭載が義務付けられていないもの
- このうち、<strong>官公庁の救難救助などを任務とする回転翼航空機</strong>は、難易度の高い運航を行うため「<strong>より強く推奨</strong>」

## ① 最低限のライン——これだけでも有効

| 項目 | 内容 |
|---|---|
| 機器 | 市販の<strong>アクションカメラ</strong>か<strong>スマートフォン</strong>（さらなる簡易型） |
| 撮るもの | <strong>計器盤</strong>（対気速度、気圧高度、姿勢、エンジン計器など）と、できれば窓の外の<strong>水平線</strong> |
| 優先順位 | 明るさの差で両方をきれいに撮れない機器なら、<strong>窓の外より計器を優先</strong> |
| 音声 | ICS（インターコム。管制交信を含む）が録れれば理想。外部音声入力のない機種は内蔵マイクだけになる |
| 航跡 | 機器のGPSで記録。機体の中央に付けると測位できないことがあるので、なるべく窓の近くに |
| 電源 | 機体に<strong>もともとある</strong>シガーソケットなどから定格内で給電するか、モバイルバッテリー |

ガイドラインの言葉でいえば、パラメータが直接記録されない機器は、<strong>計器盤の必要な計器が映る位置に付ける</strong>ことで補います。パイロットの肩や頭が映り込まない画角にするのがコツです。

### 「持ち込み品」として使う2つの条件

機体の改造（STC）によらず、持ち込み品として使う場合の条件は、次の2つだけです。

| 条件 | 内容 |
|---|---|
| <strong>条件①</strong> | 航空機の整備・改造にあたる<strong>新たな取り付けを機体に施さない</strong>こと |
| <strong>条件②</strong> | 携帯型電子機器の電波に対する<strong>電磁適合性（EMC）試験</strong>を実施し、耐性評価結果を証明する書類を<strong>保管</strong>すること |

条件②が必要になるのは、<strong>電波を出す使い方をする場合</strong>（Bluetoothでヘッドセットとつなぐなど）と、<strong>電磁適合性の安全がまだ確認されていない場合</strong>です。試験は、<strong>搭載する機体と持ち込む機器のすべての組み合わせ</strong>について、実際に使う形で行います。<strong>機器を交換したら、試験はやり直し</strong>です。

有線のマイクや、機体にもともとあるオーディオジャックにつないで音声を録る方法で、電磁適合性の安全が確認されていれば、<strong>条件①だけ</strong>で使えます。

ガイドラインには、アクションカメラで4通り、スマホで2通りの構成例が載っています。

| 構成 | 音声の取り方 | 必要な条件 |
|---|---|---|
| アクションカメラ① | 有線マイク2本をヘッドセットのマイク部とイヤホン部に付ける | 安全確認済みなら①のみ |
| アクションカメラ② | 機体側の既設オーディオジャックにカメラの音声入力をつなぐ | 安全確認済みなら①のみ |
| アクションカメラ③ | ヘッドセットとBluetoothで接続 | <strong>①と②</strong> |
| アクションカメラ④ | 音声なし、映像と航跡のみ | 安全確認済みなら①のみ |
| スマホ① | 有線マイクでヘッドセットの送受信音声を録る（航跡用アプリが必要） | 安全確認済みなら①のみ |
| スマホ② | Bluetoothで音声機器と接続 | <strong>①と②</strong> |

スマホでモバイル通信（LTEなど）を上空で使う場合は、契約している携帯電話会社への手続が別に必要です。<strong>機内モードなどで通信しない設定</strong>にすれば、その手続は要りません。

### 取り付け位置——ここは必ず守る

| | 条件 |
|---|---|
| 1 | パイロットの<strong>窓外視界や計器への視線を妨げない</strong> |
| 2 | 操縦中や上空での操作で、<strong>パイロットの体がぶつからない</strong> |
| 3 | <strong>脱出の妨げにならない</strong> |
| 4 | 振動で外れることを想定し、<strong>外れてもペダルなどの操縦操作に影響せず、乗員・乗客がけがをしない</strong>位置 |

ケーブルやハーネスは決められた場所に収納するか、テープで壁面に固定して、視界の妨げや、操縦・脱出時に引っかかる位置に置かないようにします。

この条件を満たせば、<strong>複数台の搭載も妨げない</strong>とされています（たとえば計器用と窓外用の2台）。実際の取り付け例として、Bell 505やTBM700では窓に吸盤で、R44やR22では機体フレームにマウントで固定した写真が載っています。

### 電源の注意

- 電源は、<strong>既設</strong>のシガーソケットなどを<strong>定格容量以内</strong>で使う
- <strong>新たに電源取り出し口を設ける</strong>と、STC（追加型式設計承認）か修理改造検査が必要になる可能性がある
- モバイルバッテリーを使う場合は、爆発物等の輸送基準の告示（別表第18）にある容量・個数の要件に従い、<strong>飛行後は機内に放置せず持ち出す</strong>（[モバイルバッテリーの機内持込みルール](/blog/mobile-battery-kisoku-2026/)の記事も参照）

## ② 推奨のライン——これから機器を選ぶなら

ここからは、新しく機器を選ぶときの参考です。ガイドラインも、一部のデータしか取れない機器の搭載を妨げるものではない、と断っています。

| 項目 | 推奨内容 |
|---|---|
| 飛行パラメータ | <strong>位置（緯度・経度）とGPS高度</strong>、<strong>針路</strong>（またはヨーレート）、<strong>ピッチ</strong>、<strong>ロール</strong>（それぞれレートでも可）、<strong>対地速度</strong>、<strong>3軸加速度</strong>。外付けのGPSアンテナが使える機器はより有効 |
| 音声 | ICS音声の記録。とくに<strong>ATC音声の取得を強く推奨</strong>。エンジン音などの環境音も |
| 映像 | <strong>4Hz以上</strong>のフレームレート、<strong>フルHD以上</strong>の解像度 |
| 記録の範囲 | <strong>電源ON（チェックリスト開始）から電源OFF（スポットで機体電源を切る）まで</strong>連続して記録。電源に連動して自動で記録を始める機能が有用 |
| 保存容量 | <strong>最新約10時間分</strong>を保持し、満杯になったら<strong>古いものから上書き</strong> |
| データの取り出し | 有線、無線、SDカードなどの記録媒体のいずれか |
| 解析ツール（メーカー提供の場合） | 姿勢・航跡の<strong>アニメーション</strong>と、<strong>映像・音声の同期再生</strong> |
| データ形式 | メーカーのツールがあれば問わない。なければ一般的なアプリで確認できる形式 |

10時間という数字は、訓練機関で<strong>1日分のフライトをすべて残せる</strong>ことを目安にしたものです。参考までに、事故調査用の軽量フライトレコーダーに対するEASAの規則では、飛行パラメータ最低5時間、映像・音声最低2時間とされています。

アクションカメラには電源連動の自動録画がないので、<strong>飛行前と飛行後のチェックでスイッチのON/OFFを確認する</strong>ことが推奨されています。実証調査で「押し忘れ」が報告されたためです。

## ③ 求められていないこと

- <strong>耐衝撃性・耐火性・耐水性の規格</strong>（ED-155やRTCA/DO-160など）への適合は、<strong>必ずしも求めない</strong>。米国の事故調査では、Vision1000、GoPro、Virbを搭載していた機体の記録が役立った例がある
- 可能であれば、国内外で認証を得ている機器が望ましい、という程度
- ガイドラインに従うこと自体が<strong>義務ではない</strong>

一方で、<strong>機体に新しい電源口や音声ジャックを設ける</strong>、<strong>機器を機体に恒久的に取り付ける</strong>となると、STCか修理改造検査が必要になります。迷ったら航空局安全部安全政策課に相談するよう書かれています。

## 運用の最低限

機器を付けただけでは、FDMにはなりません。運用面の最低限をまとめます。

### 飛行前のチェック

| チェック | ポイント |
|---|---|
| バッテリー残量 | 内蔵バッテリーの機器は飛行前に充電 |
| SDカードの空き | 予定のフライト分を記録できるか |
| 電源 | 正常にONになるか |
| ケーブル | 緩みや差し込み口の誤りがないか |
| 取り付け位置 | <strong>最初の取り付け位置を写真で残し</strong>、毎回それと同じ位置か確認 |

### 飛行後

- 1日の運航終了後など、決まったタイミングで<strong>データを回収</strong>する
- SDカードを使う場合は、<strong>予備を複数</strong>用意しておく
- 無線で取り出す場合は、<strong>確実に飛行を終えてから</strong>伝送する

### データの管理

- 組織内で<strong>管理責任者</strong>を決め、<strong>アクセスできる人を限定</strong>する。媒体は施錠などで管理する
- データとは別に<strong>管理簿</strong>をつける（ファイル名、飛行目的、日時、機体、操縦士のID、ヒヤリハットの有無と内容など）。操縦士は実名でなく記号にしてもよい
- 使い方ごとのルールを決めておく

| 使い方 | 扱い |
|---|---|
| そのフライトの操縦士と教官で振り返る | 管理者に伝えれば、特別な承認は不要 |
| 整備に使う | 管理者と調整し、その飛行の操縦士の利用許諾を得る |
| 他の操縦士向けの社内教育に使う | 慎重に。会話を含まない音声、操縦士が映っていない映像に限るのが望ましい。人が映る場合はモザイク等をかけ、本人の許可を得る |
| 外部に提供する | 秘密保持契約を結び、データの範囲・目的・形式などを文書で取り決める |

- 事故・重大インシデントが起きたときに、<strong>運輸安全委員会へ速やかにデータを提供できる体制</strong>を作っておく

## 何に使えるのか

ガイドラインが挙げている使い道は、次のとおりです。

- <strong>機体の不具合のモニタリング</strong>——不具合が映像やデータに残り、原因を追いやすくなる
- <strong>運航のモニタリング</strong>——操縦や標準手順、空域制限の遵守の振り返り。リスクの高い飛行への抑止にもなる
- <strong>訓練・技能向上</strong>——教官との振り返りや、自分の操縦の振り返り
- <strong>エビデンス</strong>——他の空域利用者、メーカー、近隣住民、保険会社などとの調停で、正確なデータを示せる
- <strong>事故調査</strong>——事故や重大インシデントの原因究明に役立つ

## まとめ

- 国交省の「小型航空機用FDM導入ガイドライン」（2023年8月）は<strong>推奨</strong>で、義務ではない。「<strong>音声や映像のみの記録でも十分に有効</strong>」とされている。
- 推奨対象は、記録装置の義務がない<strong>5.7t以下の飛行機と回転翼機</strong>。<strong>官公庁の救難救助ヘリはより強く推奨</strong>。
- <strong>最低限</strong>：アクションカメラかスマホで、<strong>計器盤</strong>（優先）と窓外、できれば<strong>ICS音声</strong>を記録する。条件は<strong>機体を改造しないこと</strong>と、<strong>電波を出す使い方をするならEMC試験＋書類保管</strong>。取り付けは<strong>視界・操縦・脱出を妨げず、外れても危険のない位置</strong>。
- <strong>推奨</strong>：位置・GPS高度・針路・ピッチ・ロール・対地速度・3軸加速度、<strong>ATC音声</strong>、<strong>4Hz・フルHD以上</strong>、<strong>電源ONからOFFまで自動記録</strong>、<strong>約10時間分を上書き保存</strong>、アニメーションと映像・音声の同期再生ツール。
- <strong>不要</strong>：耐衝撃・耐火・耐水の規格適合。ただし新しい電源口・音声ジャックの設置にはSTCか修理改造検査が要る。
- <strong>運用</strong>：飛行前チェック（電池・SD・電源・ケーブル・取り付け位置の写真照合）、定期的なデータ回収、管理責任者とアクセス制限、管理簿、プライバシーへの配慮、事故時に提供できる体制。
