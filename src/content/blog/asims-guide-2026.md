このブログでは、[GPSをIFRに使う基準](/blog/gps-ifr-circular-2026/)や[RNAV航行の許可](/blog/rnav-approval-2026/)の記事で、出典に「ASIMS」と書いてきました。国土交通省航空局の<strong>航空安全情報管理・提供システム</strong>のことです。

ただ、`https://www.asims.mlit.go.jp/login` を開くと、いきなり**ユーザ名とパスワードの入力欄**が出ます。ここで諦めた方は多いのではないかと思います。

結論から書きます。<strong>ユーザ名とパスワードを空欄のまま「ＯＫ」を押せば、そのまま中身が見られます。</strong>国土交通省自身がそう案内しています。

実際にゲストで入って、何が置いてあるかを確かめました。

---

## まず、ログインは要りません

ログイン画面の下に、こう書かれています。

> ログインユーザをお持ちでない方はユーザ名、パスワードを入力せずにOKボタンを押して下さい。
> **ゲストユーザ用閲覧画面にログインできます。**

航空局の[航空安全情報ポータル](https://safetyp.cab.mlit.go.jp/)側にも、同じ案内が繰り返し置かれています。耐空性改善通報のページにはこうあります。

> ※ログインユーザをお持ちでない方はユーザ名、パスワードを入力せずにＯＫボタンを押して下さい。ゲストユーザ用閲覧画面にログインできます。ログイン後、「耐空性改善通報（ＴＣＤ）情報管理」より、ご確認いただくことができます。

<strong>アカウントを作る必要も、申請も要りません。</strong>空欄のまま押すだけです。

## 何が見られるのか——13のデータベース

ゲストで入ると「**航空機安全情報 メインメニュー**」が開きます。4つの区分に、合計13のデータベースが並んでいました。

| 区分 | データベース | 中身 |
|---|---|---|
| **一般** | <strong>サーキュラー情報管理</strong> | 航空局サーキュラーの**本文PDF**。運航・整備・検査の実施基準 |
| | <strong>耐空性審査要領情報管理</strong> | 日本の**耐空性の技術基準**そのもの |
| | 超軽量動力機管理 | 超軽量動力機の型式仕様書など |
| | <strong>航空機故障報告管理</strong> | 航空機・発動機・プロペラ・装備品・部品・救急用具等の**故障情報** |
| **検査関係** | <strong>耐空性改善通報（TCD）情報管理</strong> | **日本版AD**。整備・改造の強制指示 |
| | **飛行規程情報管理** | 飛行規程（AFM）関係 |
| | 飛行検査・地上検査情報管理 | 検査関係の情報 |
| | 予備品証明対象部品情報管理 | 予備品証明の対象部品 |
| **認定事業場関係** | 認定事業場検査履歴管理 | 認定事業場の検査履歴 |
| **設計関係** | <strong>型式証明情報</strong> | 型式証明（TC）の情報 |
| | 追加型式設計承認情報管理 | **STC**の情報 |
| | 型式承認・仕様承認情報管理 | 装備品の型式承認・仕様承認 |
| | 適用基準情報管理 | 適用される基準の情報 |

ぱっと見て分かるとおり、<strong>重心は「機体」側</strong>です。設計・製造・整備・検査の情報が中心で、運航に直接効くのはサーキュラーとTCD、それに故障報告あたりになります。

## パイロットとして、実際に効くのはどれか

### ① サーキュラー情報管理——139本の実施基準

いちばん使うのはここだと思います。航空局の**サーキュラー**は、法令そのものではありませんが、<strong>「その許可・承認を取るには、実際に何をどう満たせばいいのか」</strong>を書いた文書です。

番号体系が分かりやすくできています。航空安全情報ポータルに載っている一覧（2026年9月時点で**139本**）を番号帯ごとに数えると、こうなりました。

| 番号帯 | 件数 | 内容 | 代表例 |
|---|---|---|---|
| **0-000** | 1 | 体系そのものの説明 | サーキュラー体系について |
| **1-xxx** | 47 | 航空機・装備品の検査／証明 | 航空機及び装備品等の検査に関する一般方針 |
| **2-xxx** | 9 | 事業場認定 | 事業場認定に関する一般方針 |
| **3-xxx** | 24 | 整備・改造 | 航空機の整備及び改造について／耐空性改善通報の取扱いについて |
| **4-xxx** | 18 | 事業の許可・規程審査 | 整備規程審査要領／運航管理施設等の検査要領 |
| <strong>5-xxx</strong> | **16** | <strong>運航の特別な承認</strong> | CAT I・II・III／ETOPS／RVSM／GPS／RNAV／EFB／ADS-B OUT |
| **6-xxx** | 17 | 報告制度・装備品の解釈 | 航空機故障報告制度／模擬飛行装置等認定要領／旋回計の表示について |
| **7-xxx** | 5 | 国際・一覧類 | 耐空検査員一覧／航空機及び発動機の各型式設計国一覧 |
| **8-xxx** | 2 | 無人航空機の型式認証 | 無人航空機の型式認証等の手続き |

<strong>操縦する側がいちばん見るのは5-xxxの帯</strong>です。並べるとこうなります。

| 番号 | 件名 |
|---|---|
| 5-001／5-002／5-013 | カテゴリーⅠ／Ⅱ／Ⅲ航行の承認・許可基準 |
| 5-003 | 双発機による長距離進出運航実施承認審査基準（ETOPS） |
| 5-004 | ＲＶＳＭ航行の許可基準及び審査要領 |
| **5-005** | [GPSを計器飛行方式に使用する運航の実施基準](/blog/gps-ifr-circular-2026/) |
| **5-006** | [GPSを有視界飛行方式に使用する運航の実施基準](/blog/gps-vfr-circular-2026/) |
| 5-008 | 自蔵航法実施基準 |
| 5-009 | CPDLCを使用する航空機運航の実施承認基準 |
| 5-010 | 非精密進入方式においてFMS装置のVNAV機能を使用する運航の承認基準 |
| 5-011 | RNAV運航承認基準 |
| 5-015 | Baro-VNAV進入実施基準 |
| **5-017** | [RNAV航行の許可基準及び審査要領](/blog/rnav-approval-2026/) |
| 5-018 | EFBを使用する航空機運航の実施承認基準 |
| 5-019 | ADS-BOUT機上装置を使用する航空機運航の実施承認基準 |
| 5-020 | RFレグ航行の実施要領 |

6-xxxにも面白いものが混ざっています。**6-005「旋回計の表示について」**、**6-006「精密高度計の定義について」**、<strong>6-010「航空機の着氷防止対策及び着氷状況の監視の実施について」</strong>あたりは、「あの装備の定義はどこで決まっているのか」という疑問に直接答えてくれるタイプの文書です。

そして<strong>6-013「航空安全情報管理・提供システムによる安全情報サービス利用要領」</strong>——ASIMSそのものの利用要領も、ASIMSの中に入っています。

### ② 耐空性改善通報（TCD）——郵送だと1週間かかる

TCDは、航空機や装備品の安全性・環境適合性を確保するために整備や改造が必要と認めたときに、<strong>航空機の所有者に対して発行される</strong>ものです。日本版のAD（Airworthiness Directive）と考えていいと思います。

ここで効いてくるのが、航空局の説明にあるこの一文です。

> 耐空性改善通報は、適用航空機の所有者（所有者から依頼があった場合には使用者又は整備担当者）に対して配布いたしますが、特定本邦航空運送事業者を除き**郵送により配布するため、所有者の手元に届くまでに、発行日から１週間程度かかります。**

<strong>紙が届くのを待つと、1週間遅れます。</strong>ASIMSを見れば、その待ち時間を飛ばせるということです。

参照できる範囲も明示されています。

| 期間 | 参照できる形式 |
|---|---|
| **平成21年3月23日以降** | **本文データ**の参照が可能 |
| **平成30年1月1日以降** | <strong>PDF形式</strong>での参照が可能 |
| それ以前 | 航空機安全課技術係へ問い合わせ |

### ③ 航空機故障報告管理

**航空機、発動機、プロペラ、装備品、部品、救急用具等**に係る故障情報が入っています。

自分の機種で何が起きているかを、事故調査報告書になる前の段階で拾える場所、という位置づけです。報告制度そのものは、サーキュラー<strong>6-001「航空機に係る不具合の報告・通報について」</strong>と<strong>6-002「航空機故障報告制度について」</strong>で定められています。

### ④ 耐空性審査要領

日本の**耐空性の技術基準**そのものです。FARでいうPart 23/27/29にあたる部分で、[AC 20-138Dの記事](/blog/ac20-138-2026/)で「日本の基準が一行で参照している」と書いた、その日本側の基準がこれです。

## つまずきやすい3つのポイント

実際に触ってみて、引っかかったところを書いておきます。

### ① リンクを直接踏むと、ログイン画面に飛ばされる

これがいちばん多いパターンだと思います。検索結果やこのブログの出典リンクからASIMSのPDFを直接開こうとすると、<strong>PDFではなくログイン画面が出ます。</strong>（今回も実際にそうなりました。）

航空局の通達一覧ページにも、わざわざ注意書きが置かれています。

> ※ 航空安全情報管理・提供システム（ASIMS）のログイン画面が表示される場合がございます。ログインユーザをお持ちでない方は、ユーザ名とパスワードを入力せずに空欄のままＯＫボタンを押していただき、ゲストユーザ用閲覧画面にログインした後、<strong>本ページにお戻りいただき、以下のリンク先から通達をご参照ください。</strong>

つまり手順はこうです。

1. ログイン画面が出たら、**空欄のままＯＫ**
2. メニューが出る
3. <strong>元のページに戻って、もう一度リンクを踏む</strong>

3が抜けると永遠に辿り着けません。**先にゲストログインを済ませてからリンクを踏む**と考えておくのが早いです。

### ② サブシステムは別ウィンドウで開く

メニューから各データベースを開くと、**新しいウィンドウ**で立ち上がります。ポップアップをブロックする設定にしていると、押しても何も起きないように見えます。

### ③ ホスト名が2つある

同じASIMSなのに、リンク先のホスト名が2種類混在しています。

- `www.asims.mlit.go.jp`
- `asims.cab.mlit.go.jp`

航空安全情報ポータルの通達一覧を数えると、`asims.cab` が60件、`www.asims` が68件でした。**どちらも正規のASIMS**です。片方でログインしたつもりでも、もう片方のリンクで再度ログイン画面が出ることがあるので、頭の片隅に置いておくとよさそうです。

## 探すなら、まず「航空安全情報ポータル」から

ASIMSの中は、正直なところ検索しやすい作りではありません。**探す入口としては、こちらのほうが速い**です。

<strong>[航空安全情報ポータル](https://safetyp.cab.mlit.go.jp/)</strong>（平成30年8月1日開設）

航空局安全部が一元的に安全情報を掲載するために作られたサイトで、次の2つが便利です。

**1. 通達類が、担当課室別に整理されている**

| 課室 |
|---|
| 安全政策課（旧運航安全課） |
| 航空機安全課 |
| 航空安全推進室 |
| 航空交通管制安全室 |
| 空港安全室 |
| 無人航空機安全課 |

操縦や運航まわりの通達は<strong>安全政策課（旧運航安全課）</strong>のページに集まっています。「操縦関係」「運航関係」に分かれ、さらに**操縦一般／技能証明等の手続／航空経歴／実地試験／操縦練習／航空身体検査／特定操縦技能／離着陸の場所・最低安全高度／空域／装備品・携行燃料**…と細分されています。

このブログで扱った[野外飛行の解釈（空乗第2129号）](/blog/logbook-cross-country-2026/)や[型式限定（空乗第928号）](/blog/type-training-1055-2026/)も、ここに一覧で並んでいます。**制定日・文書番号・最終改訂日・改訂後の文書番号が表になっている**ので、「自分が見ている通達が最新版か」を確かめるのに向いています。

**2. 横断検索がある**

[検索ページ](https://safetyp.cab.mlit.go.jp/search/)から、**航空局ホームページ・航空安全情報ポータル・ASIMS**の記事を横断して検索できます。ASIMSの中を直接探すより、まずここにキーワードを入れるほうが速いことが多いです。

## まとめ

- ASIMS（**航空安全情報管理・提供システム**）は、<strong>ユーザ名・パスワードを空欄のままＯＫを押せばゲストとして閲覧できます。</strong>アカウント申請は不要。国土交通省自身が案内しています。
- 中身は<strong>13のデータベース</strong>。**一般**（サーキュラー／耐空性審査要領／超軽量動力機／航空機故障報告）、**検査関係**（TCD／飛行規程／飛行検査・地上検査／予備品証明対象部品）、**認定事業場関係**、**設計関係**（型式証明／STC／型式承認・仕様承認／適用基準）。
- 重心は**機体側**。運航で効くのは<strong>サーキュラー・TCD・故障報告</strong>の3つ。
- サーキュラーは**139本**（2026年9月時点、番号は0-000〜8-002）。<strong>操縦する側が見るのは5-xxxの帯</strong>——CAT I/II/III、ETOPS、RVSM、GPS、RNAV、EFB、ADS-B OUT。
- <strong>TCDは郵送だと発行から手元まで1週間程度かかります。</strong>ASIMSなら待たずに読めます。**平成21年3月23日以降は本文データ、平成30年1月1日以降はPDF**で参照可能。
- つまずきポイントは3つ。<strong>①直リンクを踏むとログイン画面に飛ぶ（先にゲストログインしてから戻る）</strong>／②サブシステムは別ウィンドウで開く（ポップアップブロックに注意）／③**ホスト名が`www.asims.mlit.go.jp`と`asims.cab.mlit.go.jp`の2種類ある**。
- 探すなら、まず<strong>[航空安全情報ポータル](https://safetyp.cab.mlit.go.jp/)</strong>。通達類が課室別に整理され、**制定日・文書番号・最終改訂**が表で並びます。横断検索も使えます。
